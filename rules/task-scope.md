# 任务范围规则

## 围绕当前目标

所有修改必须围绕当前任务明确的目标展开，只修改完成目标所必需的代码和文件。

允许自主完成必要的关联修改，包括局部重构、跨 crate 调整及阻碍当前目标的既有问题修复，不需要逐项请求确认。

不得借当前任务顺便处理无关问题，也不得为假设中的未来需求增加代码、接口或抽象。

发现不属于当前任务范围的问题时，可以记录或报告，但不应擅自扩大修改范围。

## 开发职责

开发 Agent 只按已确认的设计完成当前功能及必要验证。不得主动扩展需求、为假设中的极端边界条件增加防御逻辑，或开展无关重构及额外优化。

完成当前任务所必需的错误处理、关联修改和缺陷修复仍然允许；任务范围外的问题只报告，不擅自修复。
