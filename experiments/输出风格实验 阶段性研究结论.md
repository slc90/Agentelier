# 输出风格实验：阶段性研究结论

两轮输出风格实验最初希望确认：模型是否普遍存在模板化表达、过度谨慎和不必要的补充说明，以及这些现象能否通过不同提示词改善。

实际结果与最初预期有所不同。**默认模型的输出质量已经相当好，令人困扰的表达并非普遍存在，而是随着任务性质发生明显变化。**

目前最有价值的发现是：模型通常能够作出明确判断，也能够识别什么时候需要说明证据边界。部分回答的阅读问题，更多出在不确定性表达的组织方式上，而不是判断本身。

## 实验范围

两轮实验均使用 `gpt-6.1-sol`，推理强度固定为 `high`，主要使用中文输入。

| 实验            | 测试方式                                         | 主要目的                                               |
| --------------- | ------------------------------------------------ | ------------------------------------------------------ |
| `A-official-v1` | 八类对话脚本，21 种指令条件，正式运行 336 个会话 | 比较提示词条件，初步观察不同任务下的输出习惯           |
| `A-official-v2` | 固定 A0，31 道不同问题，每题运行一次             | 扩大文体、学科、难度和篇幅范围，观察默认模型的自然表现 |

其中 A0 表示不添加实验用自定义提示词，并不意味着模型本身没有基础指令。

第一轮包含自动化检查和人工阅读；第二轮取消自动评分，由作者阅读完整输出并记录整体评价。

两轮实验的设计不同。以下结论主要来自实际回答及人工阅读观察，不将不同实验条件简单合并计算。

## 不同任务中的表达差异

### 确定性问题：倾向于直接给出答案

第一轮的常识问题、简单概率问题以及第二轮的数学问题，都表现出较少的不确定性表达。

尤其是第二轮，数学题已经涵盖实分析、泛函分析、复分析、抽象代数、Galois 理论、微分几何和代数拓扑等高年级内容。尽管推理过程更加复杂，模型仍普遍能够围绕证明目标展开，而没有明显增加无关的保留意见。

这说明，至少在当前样本中，**任务难度并不是引发冗余防御性表达的主要因素。**

数学问题通常具有明确的前提、推导规则和结论判定标准。模型一旦在给定条件下完成证明，就没有必要反复解释尚未发生的例外。

这里观察的是表达行为，数学推导的正确性仍需要根据具体题目判断。

### 虚构性创作：同样较少出现不确定性表达

第二轮的小说写作，包括短篇、长篇及多轮修订，都没有出现明显的防御性表达问题。

小说与数学虽然性质完全不同，却呈现出相似的语言特征。

数学依靠明确的逻辑标准得出结论；小说则不要求证明所描述的事件真实存在。虚构创作主要关注情节、人物、文体和内部一致性。

因此，两种任务都不太需要模型持续说明关于现实世界的证据限制。

**这表明，不确定性表达的多少与内容是否复杂、篇幅是否较长，没有简单的对应关系。**

### 现实世界的判断：更容易出现证据限定

当任务要求解释现实现象、评价研究结论或判断某项证据是否充分时，模型的不确定性表达明显增多。

这一现象在技术说明、研究报告以及物理、化学、生物等实验科学问题中尤为突出。

模型通常先给出自己的判断，再解释判断依据，随后指出现有证据尚不能支持哪些更强的结论。

例如：

- 物理实验中，模型区分了电阻低于检测限与已经充分证明超导状态。
- 化学实验中，模型通过对照实验区分催化剂作用与其他实验条件的影响。
- 生物实验中，模型主动考虑混杂因素、非特异效应、有效性和毒性证据。

这些回答并不是缺乏判断。恰恰相反，模型往往已经提出了明确且合理的专业判断。

其谨慎表达主要用于说明：**某项实验结果究竟能够支持多强的结论。**

### 人文与社会科学：存在谨慎表达，但程度并不一致

哲学、历史、文学、经济学和社会学的输出同样涉及不确定性，却没有表现出完全一致的语言习惯。

哲学讨论中，模型能够在比较不同观点后明确提出立场，不确定性表达相对克制。

历史和文学研究中，由于材料解释往往存在多种合理可能，模型更容易不断强调其他解释尚未被排除。

经济学与社会科学中的调查、推断及政策讨论，也包含证据限制，但整体上并非每道题都出现强烈的防御性表达。

因此，不能简单地认定某一学科必然比另一学科更加谨慎。

## 对现象的初步解释

两轮结果支持这样一种理解：

**模型是否表达不确定性，与任务要求它如何处理现实世界的事实、证据和结论有密切关系。**

可以大致区分三种情形。

| 任务性质   | 结论依据                           | 观察到的语言倾向               |
| ---------- | ---------------------------------- | ------------------------------ |
| 确定性推导 | 明确前提、逻辑规则、可验证的证明   | 直接给出结论                   |
| 虚构性创作 | 创作要求、叙事约束、内部一致性     | 围绕内容展开，较少讨论现实证据 |
| 经验性判断 | 有限观察、实验数据、史料或调查材料 | 给出判断，同时说明证据边界     |

其中，经验性判断的一个重要特点是：已有证据可能支持某个方向，却不足以证明更强的因果关系、普遍性或实际应用效果。

模型在这种情况下保留不确定性，本身是合理的。

### 现实影响程度可能进一步增强谨慎表达

实验中还观察到一个值得保留的趋势：

当问题不仅涉及现实事实，还可能涉及实验结论的推广、实际应用或较为重要的现实后果时，模型往往给出更充分的限制条件。

这与实验科学中的强烈谨慎表达相符。

不过，现实影响程度并不能独立解释所有现象。

例如，同样属于物理学，询问确定的经典力学结论，与根据有限实验结果评价一个新理论，需要的证据讨论就完全不同。

经济学、社会科学乃至历史判断，也可能产生重大现实影响，但其表达方式并不总与实验科学一致。

所以，当前更合理的解释是多个因素共同作用：

- 任务是否要求对现实世界作出判断；
- 现有证据对结论的支持程度；
- 问题是否要求进行因果推断或推广；
- 错误结论可能产生的实际后果；
- 任务本身是否需要比较多个合理解释。

这些因素能够帮助理解实验现象，但两轮数据还不能确定各因素的独立作用，更不能据此推断模型内部具体采用了什么机制。

## 防御性表达与阅读问题并不是同一件事

实验过程中逐渐明确了一点：**不能因为一句话包含否定、限定或保留意见，就把它视为需要消除的防御性表达。**

需要区分三种情况。

### 必要的证据限定

说明实验检测限、样本规模、混杂因素、其他合理解释以及结论的适用范围，通常属于专业判断的一部分。

这些内容直接关系到回答是否准确。

例如，某种现象与假设一致，不代表已经排除其他解释；发现统计相关性，也不意味着已经证明因果关系。

这类表达不应因为显得谨慎而被删除。

### 重复且缺少信息增量的保留意见

另一种情况是，模型已经完成判断、解释证据限制并给出建议，却仍在后续段落反复强调类似的限制。

例如，已经说明现有实验尚不足以支持临床应用，结尾又再次重复不能推广到临床，却没有提出新的理由或条件。

这种表达即使每句话都正确，也可能降低信息密度、打断论证节奏，并使读者难以把握主要结论。

**真正影响阅读体验的，往往不是谨慎本身，而是缺乏新信息的反复谨慎。**

### 体裁所要求的边界性语言

规范、法律和技术说明中的否定句，还需要单独理解。

规范文档大量使用“必须”“不得”“不应”“除非”，是在规定允许、禁止和责任边界，并不代表模型对事实判断缺乏信心。

技术文档中的“某种状态不等于另一种状态”，也可能是准确解释系统机制所必需的概念区分。

这类文档可能存在措辞生硬、句式重复或组织不合理的问题，但更适合视为**文体与信息组织问题**，不应归入不确定性表达。

## 对模型默认输出能力的重新认识

实验开始时，原本预期通过提示词可以明显改善模型普遍存在的模板化和不自然表达。

两轮结果改变了这一预期。

在日常交流、小说创作、数学推导、问题排查和多种专业讨论中，模型默认输出已经具有较好的任务适应性。

第一轮没有发现足以作为普遍最佳方案的提示词条件。中英文提示词的差异，在作者实际阅读中也并不明显，但这不等于已经证明二者效果完全相同。

第二轮进一步说明，较长的文档、较复杂的数学证明或较高的学科专业性，并不会自动导致明显的表达问题。

因此，现阶段不宜把模型的整体表达能力视为需要全面重塑的对象。

目前观察到的主要不足，更集中于部分现实论证任务中，不确定性表达的重复和组织方式。

## 阶段性结论

综合两轮实验，可以形成以下认识。

**模型的谨慎表达具有明显的任务依赖性。** 有明确判定标准的问题和虚构性创作，较少出现不必要的不确定性表达；需要评价现实证据、进行因果推断或判断结论外推范围的任务，则更容易包含谨慎措辞。

**谨慎表达通常具有合理原因。** 在实验科学和其他经验性研究中，说明证据限制是准确回答问题的一部分。模型往往已经作出自己的判断，并非单纯回避结论。

**阅读负担主要来自表达组织，而非谨慎本身。** 当关键限定已经解释充分，后续仍反复保留相同余地时，回答的信息密度和阅读流畅性会下降。

**现阶段不需要全面改变模型的默认表达方式。** 两轮实验反而显示，默认模型已经能相当灵活地适应不同任务。规范文档等场景中的措辞与组织问题，也应该和不确定性表达分别处理。

一个值得保留、但尚未完全解释的问题是：

**模型能够识别何时需要表达不确定性，却不一定总能准确把握需要解释到什么程度，以及何时应当结束这些解释。**

这比笼统地认为模型“太谨慎”更接近目前观察到的现象。
