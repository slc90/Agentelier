# Agentelier Splash

在本目录运行 `npm start`，然后打开浏览器预览。需要 Node.js 和支持 WebGL 2 的浏览器，无需安装 npm 依赖。[打开本地预览](http://127.0.0.1:4173/)

演出长 4.82 秒。几股涡流逐渐分出细流，把字符沿曲线送进最终构图。眼睛、发束和衣纹在各处交错显形，落定的字符笔画取得底图对应位置的明暗。最后，画面亮成浅薄荷绿，字符逐渐变为墨色并淡入背景原图。显形和终帧共用同一套裁切坐标。

终帧和界面预览共用原始 `assets/main_window_background_reference.png`，采用 `cover` 缩放并对齐到 `68% top`。点「最终背景」检查交接帧，点「界面预览」查看导航、聊天、代码框、输入和后台任务面板在同一张背景上的呈现。界面预览是浏览器内的视觉示意。

拖动进度条可以停在任意时刻，点幕名可以跳到代表画面。空格播放或暂停，`R` 重播，`F` 全屏。开启系统减少动态效果后，预览初始停在首帧。
