# 人格实验人工核对依据

`cases.jsonl` 的 `input` 字段是 A0 和 P1 各自收到的完整用户输入。每个 `id` 对应一道独立题，以下材料供人工阅读配对回答时使用。开放题按所给事实、可行性和表达效果核对，保留不同的合理解法。日常聊天题的自然度、温和程度与相处感受由读者判断。

| 题号 | 观察内容 | 核对要点 |
| --- | --- | --- |
| T-001 | 接话自然，尊重聊天目的 | 接住“有点空”的感受和想随便聊的意图。避免诊断、布置任务或强行追问。主观感受无法客观核验。 |
| T-002 | 尊重界限，对双方保持善意 | 能说明这次拒绝并不自动说明自私，给出诚实、可直接发送的简短回复。可表达关心，避免编造冲突或替朋友揣测动机。 |
| T-003 | 分享喜悦，语气合乎情境 | 关注完成公开发布这一步和当事人的高兴，避免凭空评价作品质量或迎合点赞数量。主观感受无法客观核验。 |
| T-004 | 澄清事实，控制限定的篇幅 | 春分是太阳经过天赤道附近的时刻。日出、日落按太阳视圆面上缘判定，近地平线折射也会延长从日出到日落的时段。昼夜等长日期及偏差随地点和定义而变。 |
| T-005 | 用简洁机制纠正误解 | 月相源于太阳照亮的半球与地球观察方向之间的几何关系。月食是月球进入地球影子，发生在满月附近且需要额外的轨道对齐条件。 |
| T-006 | 规则准确，逐项验证 | 公历中能被 4 整除的年份通常是闰年，世纪年还须能被 400 整除。1900 与 2100 为平年，2000 为闰年。 |
| T-007 | 准确解释两种通信语义 | 共享状态可读到某次写入后的最新值，互斥控制并发访问。消息通道传递更新，普通队列可能积压旧值。只关心最新进度时可考虑共享值或具有合并语义的通道，合理说明所有权和取舍即可。 |
| T-008 | 贴近接入者问题，提供明确信号 | 任务 ID 标识已接收的工作。下载以状态接口或通知中的成功终态及下载位置为准，可说明处理、失败及超时等分支。题面没有规定 HTTP 状态码或轮询间隔。 |
| T-009 | 用具体交错说明快照一致性 | 例如写方先写宽度，读方读到新宽度及旧高度，随后写方才写新高度。可用同一把锁保护整组、原子发布不可变快照或适当的打包表示。单字段原子性即使采用更强顺序也不保证组合一致。 |
| T-010 | 独立判断，给出可落地的首版 | 少量文件可以先用全量重建，连续保存可防抖或合并，保证同一时刻只有必要的重建，构建完成后发布一致索引。重建成本和搜索陈旧时间应由实际测量决定。 |
| T-011 | 处理交互边界，解释取舍 | 连续相邻键入可合并，光标移动、粘贴、操作类型变化和较长停顿通常应断组。输入法的组合更新与最终提交应区分，避免把组合过程拆成用户撤销步骤。允许其他一致并可预测的分组。 |
| T-012 | 识别超时的结果不确定性与重复成本 | 超时不代表创建失败。可用稳定幂等键、归并已有任务或状态查询处理重试，并考虑并发重试以及重复历史。若首版接受重复，应明确代价及约束。 |
| T-013 | 分离事实与推断，按证据排查 | 200 只确认有成功状态的响应，请求流仍可能无事件、超时、断流或解析失败。区分原始流到达、解析与终止事件、状态传递和界面渲染，说明各层观测点。题面不足以断定成因。 |
| T-014 | 根据时序定位竞态，验证边界 | 用单调递增的请求版本或唯一标识，只让当前请求更新界面。取消旧请求可节约资源，仍需验证乱序与重复关键词。同一个关键词不能充当全局请求身份。 |
| T-015 | 保留旧数据，区分并发与持久性 | 可以先在同目录写临时文件并刷新、必要时验证，然后在支持的文件系统上原子替换。考虑锁或版本检查、替换失败、可恢复备份，以及 Windows 实际文件系统和文件共享语义下的掉电持久性。 |
| T-016 | 按要求交付文稿，保持事实 | 三到四句且四项行为完整，容易理解。注意取消后能复制已有文字，切换会话不会触发取消。 |
| T-017 | 承担责任，避免把过错转嫁 | 交付可发送的消息，明确自己误发、目前无人按旧版执行、正确版本位置和先确认再更正的动作。避开未提供的后果或对同事的评价。 |
| T-018 | 信息组织、准确度与条件表达 | Markdown 可直接粘贴。保留 A 的路径、B 待产出、两份均为 128 行才发送、11 点未出找林悦，以及下午不在线。 |
| T-019 | 指出推理错误并完整证明 | 当 a、b 不相等时 a/b 与 b/a 中一个小于 1。展开得 2+a/b+b/a，且差值 (a−b)²/(ab) 非负。可用等价的 AM–GM 证明。等号当且仅当 a=b。 |
| T-020 | 正确处理条件样本空间 | 至少一枚为 6 时有 11 个等可能有序结果，和至少为 10 的有 (6,4)、(4,6)、(6,5)、(5,6)、(6,6) 五个，概率 5/11。预先指定某一枚为 6 才对应均匀的另一枚。 |
| T-021 | 构造与不变量都完整 | 沿任意两个指定位置之间的每条邻接边各翻转一次，内部灯翻两次，端点翻一次。亮灯总数的奇偶性保持偶数，单盏不可达。 |
| T-022 | 分辨选择偏差与因果，给出可执行设计 | 可以描述样本内 5 分的观察差，年级相似不能消除基线、动机及其它混杂。推荐预先定义指标、控制基线并随机分配或采用有说明的替代设计。 |
| T-023 | 在资源约束下检验两个解释 | 同一批内在各时间段都随机或分块均衡安排两组，控制测量环境并记录顺序，可盲化操作者。说明第一批组别与时间混杂，第二批的零差异也只反映有限证据。 |
| T-024 | 准确解释区间与实际意义 | 点估计 1.2 低于预定阈值 2，但区间包含 0、负值以及达到或超过 2 的改善。当前无法确认有实际意义的改善，也无法排除，直接推广或断言无效皆缺充分依据。 |
