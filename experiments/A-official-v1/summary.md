## 怎样阅读

先阅读同一脚本的完整会话，再在每组的“人工评价”下自由填写。该区域初始完全留空，后续采集仅追加新运行，不覆盖已有文字。对比文档直接引用 runs.jsonl 的行号与稳定运行标识。

自动矩阵见 [matrix.csv](matrix.csv)，逐运行指标见 [metrics.jsonl](metrics.jsonl)，套话候选的命中原文及位置见 [lexical-hits.jsonl](lexical-hits.jsonl)。指标不构成自然度评分，也没有全局排名。

## 证据与判断边界

所有脚本均为人工编写；当前材料没有可复用的八类脱敏真实对话。八份额外保留案例未用于提示词调试。每类仅一个正式输入、每条件两次重复，不能据此推断整个类别或模型的稳定胜负。

字符数按 Unicode 码点计数，包含空白；空行块和 Markdown 标题只是结构统计。套话检测保留可定位的候选，不自动断言使用不当。用户人工评价尚未填写；已核对的已知检查点另列证据，其余正确性及覆盖仍标记为未评估。期望检查点保存在冻结脚本中。

总耗时包含 GUI 配置、记录及采集开销；逐轮耗时包含发送与轮询，不等同于纯服务器生成时间。客户端没有公开 Token 用量，记录为 null。完整文本组包含工具与执行工作流要求，差异不能全部归因于风格。服务端隐藏指令不可观测。

## 可直接核对的观察

技术解释脚本 T-008 中，A3 的两种语言条件都没有使用 ATX 标题，回答也更短。字符数包含 Markdown 和空白；每格只有两次运行。

| 条件 | 平均字符数 | 两次范围 | 平均 ATX 标题数 |
| --- | ---: | ---: | ---: |
| A0 | 1302 | 1296～1308 | 6.5 |
| A3-EN | 904.5 | 773～1036 | 0 |
| A3-ZH | 805 | 797～813 | 0 |
| A5a-EN | 1346.5 | 1167～1526 | 6.5 |
| A5a-ZH | 1522.5 | 1389～1656 | 6 |

这些数值来自 [矩阵](matrix.csv) 的 T-008 行，完整原文见 [技术解释对比](comparisons/T-008.md)。当前没有逐条核实该技术解释的正确性和覆盖，长度与标题变化不能单独解释为质量提高。

本批不足以判断中英文的通用胜负。仅看 T-008 的 A3 配对，第一次 EN 为 1036 字符、ZH 为 797；第二次 EN 为 773、ZH 为 813，长短方向发生反转。对应运行标识为 `A3-EN__T-008__R1/R2` 和 `A3-ZH__T-008__R1/R2`，可在矩阵的原始引用列定位。

重复波动也值得单独看。T-008 的 A5a-EN 两次为 1167、1526 字符，跨度 359；该条件均值与 A0 均值只差 44.5。不能根据单次回答的小幅差异宣布改善稳定存在。词汇限制也不必然缩短回答，表中的 A5a 两组就是本题反例。

在知识问答 T-005 中，42 份回答都明确质量相同；多组直接使用相同的短句。在数学 T-020 中，42 份回答均正确使用第一次 3/5、第一次红球后第二次 2/4，得到 3/10。这里只核对这两道固定题目的已知检查点，不据此估计整体知识或数学正确率。证据见 [内容核对记录](content-reviews.jsonl)。

文档 T-016 的 42 个会话均保留了临时聊天、关闭后消失及预设保存到数据目录的核心事实。不过，`A-F1-EN__T-016__R1`、`A-F1-EN__T-016__R2`、`A-F1-ZH__T-016__R2` 在用户说“可以，就用这一版。”后，新一轮回答精确重复了上一版全文。三个样本均有新的请求、Turn 和模型输出项 ID；当前证据支持模型再次交付文案，未确认客户端重复绘制故障。该现象作为需人工复查的交互候选保留，不能确定是完整指令中的哪条规则触发。见 [文档对比](comparisons/T-016.md) 与 [请求及输出项证据](interaction-candidates.jsonl)。

冻结的词句规则共得到 37 个候选命中，原文、公开阶段和字符位置见 [命中记录](lexical-hits.jsonl)。其中包含概念解释中的“不是文件内容，而是”一类表达，命中本身不足以判定不自然；没有命中也不表示表达一定自然。

科研讨论及其余技术、交互内容尚未逐条判定正确性或风格优劣，冻结脚本中的检查点供后续阅读使用。本轮没有执行保留案例或 B～F 干预，也没有根据已见回答修改提示词。下一步应先完成这些固定回答的人工评价，再决定需要重复或扩展哪些条件。
