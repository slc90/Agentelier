# 冻结指令材料

`effective-instructions.jsonl` 是全部 21 个条件的权威快照，保留全文、来源、版本、语言、槽位、消息角色与顺序、SHA-256。实际会话和逐轮请求证据另保存在原始运行记录中。

`A-F3-EN.md`、`A-F3-ZH.md` 可通过客户端普通 UTF-8 导入复用。它们按 A1、A2、A3、A4、A5a、A5b、A6 顺序连接原始切片，未润色正文；属于派生组合，不是原始 `style-excerpt`。F3 在本批中作为基础文本覆盖条件，十四个单片段则使用默认基础加一个补充消息。

原始材料及中文译文的归属说明见 [NOTICE](../../../crates/ui/assets/src/assets/prompts/NOTICE.md)，许可见 [Apache-2.0](../../../crates/ui/assets/src/assets/prompts/LICENSE-APACHE-2.0.txt)。完整指令中的工具描述不赋予本客户端这些工具能力。
