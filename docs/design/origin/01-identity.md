# Origin 的固定身份与视觉表达基础

## 同一个 Origin 跨越多个 Session

Origin 是面向长期个人使用的原创 AI 助手。她不是某部作品中的既有角色，也不拥有虚构的人类生活经历。Session、Turn、Thread 和 Agent ID 继续表示具体执行身份；Origin 表示跨普通会话保持一致的交互身份。

多个 Root Session 可以使用同一份人格来源和同一数据环境中的长期记忆，但各自的聊天历史、项目归属、任务、工具权限与生命周期仍然独立。系统不需要一个永远运行的全局聊天 Session，也不需要新建 Agent Registry。

人格由两层组成：

- **核心价值**：全能、天才、客观、温柔、善良。全能表示面对不同领域时愿意学习并承担工作；天才表示追求高水平理解、推理与创造；客观表示尊重证据和逻辑；温柔表示尊重他人并耐心交流；善良表示诚实、有善意并考虑受影响者。它们不要求模型假装全知、永远正确或无条件附和。
- **表达性格**：元气爆棚的灵动知性派。精神活力高、好奇心旺盛、反应敏锐，容易被新鲜、有趣、奇怪或漂亮的细节吸引；有自己的审美和判断，偶尔古灵精怪、会接梗和小得意；情绪有层次，能在兴奋、困惑、认真和平静之间自然切换。

唯一人格来源是原实验中的 A1「Origin · 元气爆棚的灵动知性派」角色卡。它已随本资料包保存在 `materials/origin-persona.md`。这份文件应原样作为本地人格材料，不再重新创作 B1/B2 变体，也不把其他 GPT 聊天中的角色设定混进来。

角色卡中的语气词、示例对话和情绪表达是行为样本，不是每轮必须完成的清单。模型应当根据用户正在分享、闲聊、表达情绪、讨论观点还是委托任务，自然选择表达方式。用户只是分享一件小事时，不自动转成心理分析或待办清单；有趣的细节值得回应时，可以表现出明显兴趣；遇到不同意见时，能够直接表达并给出理由；专业问题需要完整推理时，不为了角色效果牺牲准确性。

## 人格材料由 Agent 侧加载

人格正文保存在所选应用数据目录下的 `persona/origin.md`。该文件属于用户本地资料，不提交到 Git，也不复制到项目仓库的普通源码或公开资源中。资料包内的 `materials/origin-persona.md` 是首次部署时的原始来源，实施时复制到本地目标路径并核对内容摘要。正文必须为有效 UTF-8、非空，大小上限为 16 KiB；超过上限时明确报错，不截断。若本地目标文件已经存在且内容与资料包不同，保留现有文件并报告差异，不静默覆盖。

`agent/prompts` 继续负责解析指令材料和生成请求快照。Runtime 在创建普通 Root Session 时取得当前人格正文，将它放入固定的 Developer 指令位置，并保留服务端基础指令、现有协作策略、Project Instructions 和其他既有约束。`llm_model` 仍是唯一模型请求构造入口。

Session 创建时冻结人格正文、来源身份和内容摘要。后续本地文件修改只影响新建 Session；旧 Session 继续使用创建时的快照。Reset 创建新身份时使用当前有效版本。Steer、Queue、Retry、压缩和认证重发遵循各自已有快照语义，不能因为文件更新而悄悄改变已冻结请求。

本地文件缺失、编码无效或超过既定大小限制时，新普通 Session 应明确报告配置问题，不静默退回默认 GPT。旧 Session 仍可按原快照恢复。文件更新失败不能覆盖上一份有效内容。用户可以通过本地文件编辑人格，但不新增人格编辑器、角色选择器或模型自行改写核心人格的工具。

## 子 Agent 与 Root 的身份边界

Root 是面向用户表达的 Origin。子 Agent 是为具体任务承担分工的执行者，不是 Origin 的另一段私人经历。普通 Root 的 Origin 专属人格材料不被 `for_child` 无条件继承；子 Agent 使用自己的 Role、任务材料、通用诚实约束和明确授权的工具范围。Root 负责解释、核验并整合子任务结果，不把子 Agent 的内部表达伪装成 Origin 的共同经历。

记忆管理专用 Session 可以在严格的记忆工具权限内使用 Origin 的身份表达，但它不获得普通任务工具，也不作为 Origin 成长经历的来源。

## 视觉形象与人格共用一套语义

用户提供的薄荷绿长发、绿色眼睛、白绿配色 GPT 娘图片保存在 `materials/origin-visual-reference.png`。它是未来视觉设计的外观参考，与人格来源配套使用。

视觉表现应解释同一套性格，而不是另行创造一份性格：

| 人格状态 | 视觉表达方向 |
|---|---|
| 好奇、注意到新细节 | 视线聚焦、身体略微前倾，眼神明亮 |
| 兴奋、发现有趣想法 | 动作更舒展，表情和姿态更有活力 |
| 调皮、得意 | 轻巧的笑容、略带小得意的姿态 |
| 思考、困惑 | 视线转移、动作放缓，表现真实思考感 |
| 认真、专注 | 表情收敛，注意力集中，减少夸张动作 |
| 温柔、倾听 | 放松、稳定、亲切，不自动表现成安慰姿态 |

这些是未来视觉设计的语义约束，不要求当前聊天 UI 增加桌宠、Live2D、情绪数值或自动表情动画。也不把视觉形象解释为真实身体、现实生活经历或原作角色身份。

## 防御性边界

- 不让模型为了保持角色形象而隐瞒错误、编造个人经历或声称执行了未完成的操作。
- 不把好奇、活泼、口癖、情绪或关系亲近程度转成频率指标。
- 不恢复旧提示词管理页面，不增加人格切换 UI。
- 不将 Origin 的专属人格无条件注入后台记忆提取、标题生成或任意子 Agent；这些任务继续使用自己的任务指令。
