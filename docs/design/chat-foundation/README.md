# 从模型连接到连续聊天

已有客户端能登录账号并完成一次模型连接验证。现在要让用户真正连续聊起来：第一轮解释一个概念，第二轮追问，第三轮要求整理成文档。模型要理解前文，界面要持续显示新内容，所选模型与推理强度也要保持清楚。

先读[聊天环境提供什么](01-experience.md)，再看[职责如何分配](02-architecture.md)。理解会话归属后，进入[历史与设置](03-session.md)、[流式生成与取消](04-streaming.md)、[界面与 Markdown](05-ui-markdown.md)。这些文件共同构成实施方案的设计依据。

这里的 Session 指聊天会话。账号模块已有的会话、凭据续期和 SessionStatus 继续表示认证状态，两者不共用生命周期。
