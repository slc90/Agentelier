# 聊天会话与流式回复

主界面先刷新模型目录、选择模型及推理设置，再点击“创建会话”。会话固定这份设置和当前账号身份；之后修改准备区不改变已经创建的会话。当前保留一个内存会话并支持连续多轮交流，关闭应用后不会恢复记录。

模型准备区的“提示词管理”提供来源浏览、编辑为新版本、UTF-8 文件导入、基础文本覆盖、有序补充指令和组合预设保存。新建会话固定当时的完整有效指令；之后改库、切换组合或编辑准备区不改变现有会话，重置复制当前会话快照，失败及取消后的重试同样保留原快照。“会话与请求核对”可查看模型、推理强度、完整来源版本快照及最近一次请求的指令消息。使用方式与限制见[提示词管理与会话指令](prompts.md)。

输入框支持多行和粘贴，Enter 发送、Shift+Enter 换行，发送按钮提供相同操作。空白输入不能发送，正文中的换行和空白保持原样。IME 预编辑及候选提交帧不触发发送。业务接纳前保留草稿；接纳后清空尚未继续编辑的原草稿，生成期间可以编辑下一条内容，但不能排队或并行发送。

回复以原生 Markdown 持续显示，每个消息输出项保持自己的身份和公开阶段，例如 commentary 和 final_answer。内容段按服务顺序排列；流式更新修改同一行，不为每个片段创建新消息，不重建输入框。切换设置页不取消生成，返回时恢复当前记录。标题、段落、强调、删除线、行内代码、引用、分隔线和链接已有排版；有序、无序和嵌套列表保留层级及起始编号；围栏与缩进代码块保留语言标签、缩进、换行和空行，长行在代码区域独立横向滚动。GFM 表格以真实行列和表头显示，保留列对齐与单元格行内样式，窄幅在表格区域横向滚动。任务列表以只读勾选状态显示。

只有合法完成响应及可接受的完整输出才标记完成，并以最终正文校准此前增量。失败或取消保留部分回复并说明状态；未完成内容不冒充完整答案。没有可展示正文时只显示完成状态。普通拒绝正文正常显示，结构化 function_call 进入下述 Direct 工具执行路径，未支持的输出类型明确失败。

聊天使用 `store=false`、固定流式请求，不加载自定义风格提示词。无总生成时长上限，合法 SSE 事件或心跳维持 120 秒空闲期限；连接超时为 15 秒，单事件上限 4 MiB、总流上限 16 MiB。超时、超限、断流、服务拒绝和不完整结果保留实际原因，输出开始后不自动重放请求。

任务真实结束并回收后才发布最终状态。普通关闭取消生成，等待必要凭据提交及 Tokio 结束，保留账号会话。自然凭据续期不清空聊天；账号身份改变后不能继续沿用旧会话。

实现关系见[总体架构](../design/architecture.md#内存聊天与流式投影)。协议依据：[Responses 流事件](https://developers.openai.com/api/reference/resources/responses/streaming-events)。

## 连续交流的上下文

上一轮的真实终态和任务回收完成后，才允许发送下一条消息。下一次请求由执行侧的已提交协议历史和当前输入组成，不读取 UI 气泡拼接上下文。会话内可以持续追问、修订前文和整理文档；历史消息保留在滚动列表中。

纯聊天只有成功响应把用户输入和完整输出一起提交；工具任务按完整响应和全部工具结果形成提交点。失败、取消或断流保留此前完整步骤，当前未完成响应只供回看，不进入后续上下文。原有公开阶段、消息顺序和所需的加密 reasoning 项按协议保留，加密内容不进入 UI 或日志。

生成中仍可编辑草稿，发送不可排队。修改准备区的模型或推理强度不会改变活动 Session 的设置，后续请求继续使用创建时快照。上下文超限时显示实际错误并保留记录，不自动摘要、压缩、裁剪或截短输入。

## 停止生成

生成期间可点击“停止”。界面先显示正在停止，等待对应任务真正结束与回收后才恢复发送。停止保留当前账号、会话和已显示正文，并区分已保留完整步骤与未进入上下文的片段。控制路径独立于正文传递，按会话、轮次与操作身份核对；已经确认完成的结果不会被迟来的停止回滚。

## 重试最近尝试

最近一次失败或取消、尚无提交点的尝试在任务回收后可手动重试。重试使用同一输入、活动会话设置和此前成功历史，分配新轮次及操作身份；同一个用户输入只显示一次，旧尝试及部分正文继续保留。新尝试不携带旧部分回答或错误文本，接纳不清空正在编辑的新草稿。后续已继续交流时不能回到旧失败条目原位重试；没有自动重试或分支回滚。

## 新建和重置

“新建会话”复制准备区的模型与推理设置，“重置当前会话”复制当前活动会话设置。已有会话时先提示记录未持久化，点击确认后才清空全部展示与协议历史；输入草稿保留，保留按钮撤回清空。新会话身份重新分配，账号和数据目录不变。生成、停止中或尚未回收时两项操作均禁用，执行侧同样保护运行中的会话。

## Markdown 阅读

助手正文保留原始 Markdown，由原生 Bevy/Widgetry UI 展示；HTML 按字面文本显示，图片仅显示替代文字和目标，不下载远端内容。链接正文保留样式，下方按钮只在用户点击时打开 HTTP/HTTPS 目标；其它 URI 显示但不执行。

生成期间只重新解析发生变化的消息，未变化的块保持实体。位于底部时跟随新内容；向上翻阅后保留阅读位置，点击“回到底部”恢复跟随。切换设置页后恢复记录及阅读位置，不重新发起生成。

## 原文和复制

每条助手消息可在排版和可选择的只读原文区域之间切换，并复制当前原始 Markdown 正文；正文复制不含角色、阶段、状态或按钮文字。生成时原文持续更新，复制取得点击时的快照，不停止请求。代码块有独立复制入口，只取代码正文，保留缩进、换行和空行，不带围栏和语言标签。复制成功或失败显示在对应按钮上，使用本机系统剪贴板。

取消或失败后的部分回答仍可查看、选择和复制，原有状态继续显示。当前不支持跨多个渲染块统一拖选；完整文本选择使用原文区域。

聊天任务由独立运行器推进，停止后等待实际回收再释放占用。如果执行任务异常退出、无法归还可信记录，会话停止接纳发送与重试，并要求重置或新建会话；尚无提交点的普通取消与网络失败仍保留原重试行为。

## Direct 工具调用

新会话固定诊断工具目录：diagnostic_calculate 支持两个有限数的加减乘除，diagnostic_wait 支持 0–30000 毫秒的异步等待。成功结果带执行时生成的随机 receipt。当前每任务最多 32 次模型请求及 64 次工具调用，同一响应可提出多项调用，按输出顺序串行执行，超额明确触限；应用等待合法完整响应后才执行。单工具期限为 15 秒，参数及结果各限 64 KiB；业务错误和超时可反馈模型，停止取消当前等待且不启动后续调用。工具不访问文件、Shell、网络或凭据。

任务内请求序号和调用/结果详情可在“提示词管理 → 会话与请求核对”查看。失败或停止后完整工具步骤保留在上下文，未完成响应仅供展示；已经有保留步骤的任务不能原样重试，可发送新消息继续。工具卡片按请求和输出顺序嵌入同一内容流，显示名称、参数与结果摘要以及接收中、待执行、执行中、成功、失败、超时、取消或未执行状态。可展开只读详情核对本次参数、结果与 call_id，展开状态跨切页保留。工具更新复用行实体与编辑器，保留草稿和原有底部跟随规则。运行中补充已接入，排队尚未接入。

## 补充当前任务

任务运行时，主按钮和 Enter 改为“补充当前任务”。模型请求或工具仍先完成当前步骤，补充消息可以及时被接纳，但只在下一次模型请求中生效。旧批次尚未开始的工具收到明确未执行结果，当前执行不会因补充而中断；立即停止仍使用 Stop。最多 8 条待生效补充，满时拒绝并保留草稿。

接纳和生效分别显示，只有接纳成功且草稿内容与修订仍匹配时清理原草稿。补充输入不改变会话设置或刷新预算。已经应用的补充消息进入用户历史，后续请求失败仍保留；停止、触限或失败前来不及应用的消息保留为未生效。任务已经结束时迟到的补充被拒绝，不转换为普通发送。Shift+Enter、IME 提交帧和 Tab 规则保持原样。
