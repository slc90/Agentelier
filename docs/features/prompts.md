# 提示词管理与会话指令

模型准备区点击“提示词管理”，可在“提示词库”“组合与预览”“会话与请求核对”之间切换；“返回聊天”保留现有聊天和生成任务。

## 来源与编辑

内置英文原文及中文译文包括 `model-main`、`default-base`、`style-excerpt`，另有 A1、A2、A3、A4、A5a、A5b、A6 共十四个语言切片。A6 不包含 PR 写作小节，已有 `style-excerpt` 仍保留其原始摘录范围。来源保留名称、编号、语言配对、版本、全文或切片性质、范围、上下文依赖及 SHA-256。来源中的工具描述不赋予客户端工具能力。

在提示词库选择条目可查看正文和来源信息，修改名称、正文或编辑语言后点击“保存为新版本”。编辑内置只读来源会建立独立派生条目，编辑已有自定义条目追加新版本；旧版本继续可选，已有组合和会话引用不被迁移。“新建”提供空白自定义条目。“导入并保存”读取输入的绝对路径所指 UTF-8 文本，不需要原生操作系统文件选择器；导入语言使用当前编辑语言。文件来源及完整文本随版本保留。

提示词库和组合预设保存在当前数据目录的 `prompts.json`，后台原子保存成功后才更新已保存状态。加载、导入或保存失败会显示实际错误；加载失败可通过“重新加载库”重试，原文件不会被默认值覆盖。未保存的编辑及当前准备区组合仅保留在内存中，组合需命名保存后才能在下次启动加载。聊天历史仍不持久化。

## 组合与生效

选择提示词版本后，可用该版本覆盖客户端基础文本，或按需追加为补充指令。默认基础条件沿用当前请求行为，即不添加客户端基础文本；默认基础加空补充对应无客户端自定义指令。补充列表提供上移、下移和移除；移除停用该项，重新追加可启用。组合预设保存基础条件和补充版本及顺序，同名保存更新该预设。

预览显示基础覆盖条件及发送的完整有序消息，每条包含 `developer` 角色、槽位、版本和内容哈希。基础消息先于补充消息，之后才是成功的聊天协议历史及当前用户输入。基础与补充是管理槽位，实际协议角色相同；不能据此宣称替换服务端隐藏指令或获得不同系统优先级。

返回聊天后创建新会话才采用准备区组合；已有会话不会随库或组合改变。重置当前会话沿用旧快照并清空历史，重试沿用失败或取消时的会话设置。会话核对视图显示当前 Session 的固定模型、推理强度、完整指令来源快照，以及最近请求的指令角色、顺序和正文。该视图不展示凭据或加密推理内容。

当前功能验证使用 `gpt-6.1-sol`、推理强度 `high`；客户端仍允许按目录能力选择其他模型和推理设置。内置 `model-main` 的来源模型归属仍为 `gpt-6-astra`，与实际请求模型独立。

本功能不包含批量实验调度、自动评分、实验报告、按场景切换提示词、聊天历史持久化或模板变量展开。组合空白也不表示服务端没有隐藏指令。
