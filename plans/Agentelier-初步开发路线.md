# Agentelier 初步开发路线

## 开发顺序

| 顺序 | 功能                   | 完成后能做什么                                                                         |
| ---- | ---------------------- | -------------------------------------------------------------------------------------- |
| 1    | **ChatGPT 登录**       | 使用自己的 ChatGPT 账号登录，并完成一次基本的模型请求；不实现 API Key 等其他登录方式。 |
| 2    | **输出内容实验**       | 调整提示词，保存并比较同一任务下不同策略的模型输出，逐步改善文字的可读性和表达方式。   |
| 3    | **基础对话能力**       | 支持多轮对话、流式输出、中断生成和持续交互。                                           |
| 4    | **Agent 工具调用**     | 让模型选择并调用工具，读取结果后继续推理，形成完整的 Agent 执行循环。                  |
| 5    | **本地开发工具**       | 逐个增加文件读写、搜索、Shell 命令、补丁应用、Git 等常用开发能力。                     |
| 6    | **会话与上下文管理**   | 保存和恢复会话、组织历史消息、控制上下文长度并支持上下文压缩。                         |
| 7    | **项目感知与指令系统** | 识别项目环境，读取 `AGENTS.md`，组织不同来源的指令。                                   |
| 8    | **Skills 系统**        | 发现、加载、选择与使用 Skills。                                                        |
| 9    | **MCP 与扩展工具**     | 连接 MCP Server，使用外部工具，并逐步扩展其他集成能力。                                |
| 10   | **多 Agent 协作**      | 创建子 Agent、分配任务、交换信息并协调执行。                                           |
| 11   | **长期记忆**           | 从历史任务提取、整理并复用有价值的信息。                                               |
| 12   | **其他高级能力**       | 视兴趣与实际需要探索 Code Mode、复杂计划、多模态、远程环境、自动化任务等。             |

## 阶段划分

### 阶段一：能实验的模型客户端（功能 1–3）

完成登录、基础模型交互和输出实验。此时还不是能自主操作环境的完整 Agent。

### 阶段二：具备行动能力的 Agent（功能 4–7）

建立模型—工具—结果反馈的循环，逐步支持本地开发任务，并管理会话、上下文和项目指令。

### 阶段三：可扩展的 Agent（功能 8–9）

通过 Skills、MCP 等机制引入可复用或外部提供的能力。

### 阶段四：探索复杂能力（功能 10–12）

研究多 Agent、长期记忆及其他高级功能，具体取舍依据实际需求和实验兴趣。
