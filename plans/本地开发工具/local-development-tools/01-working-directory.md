# 固定会话的本地工作目录

本增量让用户能够明确指定工具的默认工作目录，并在新建会话时固定它。交付的是可观察的目录设置和一致的路径语义，不是项目发现系统。现有诊断工具继续保留，后续命令、补丁和图片增量使用这里建立的快照。

```mermaid
flowchart LR
    UI[准备区目录设置] --> B[Conversation Bridge]
    B --> C[会话创建与校验]
    C --> S[不可变工作目录快照]
    S --> V[会话核对视图]
    S --> T[后续工具执行上下文]
```

## 从准备区到会话

准备区增加“本地工作目录”，支持输入绝对路径和复用现有 Widgetry 目录选择能力。初始值取应用启动时读取的进程工作目录并显示解析结果；读取失败保持未选状态，不改用账号数据目录。

Agent 侧负责路径校验和快照，UI 只提交候选路径。创建会话时目录必须已存在且确实为目录。失败保留用户输入并返回明确原因，不能静默建立拼错的目录。

准备区改变只用于新的会话。重置与重试沿用原会话目录，Steer 和 Queue 使用其所属会话快照。目录与模型、账号身份和提示词快照一样有稳定归属；不能因为设置页重新装配就被清空，也不能在运行中由一个 TextField 改写活动任务。

目录设置仅保留内存状态，不新增最近项目列表或持久化配置。没有选择有效目录时，明确阻止创建需要本地工具的会话。

## 路径解析契约

后续 `exec_command.workdir` 与 `apply_patch.workdir` 的 `null` 表示会话目录，相对值从会话目录解析，绝对值直接使用。`view_image.path` 的相对路径也从这个目录出发。参数不是 Shell 代码，不在文件路径字段里执行变量展开。

Shell 工作目录通过启动 API 单独传入；禁止改变应用全局进程目录。模型命令中的 `Set-Location` 只改变该进程，不改变其他调用的默认目录。UI 使用路径显示形式，I/O 和目录比较使用真实路径对象。

模型通过工具描述了解默认目录，通过实际工具结果核对本次目录；不增加实验 Developer 提示词，不要求加载整个 AGENTS 指令系统。考题中的规范读取仍由模型主动使用工具完成。

## 在原有职责内实现

目录快照属于 `agent/conversation`，路径解析与执行环境值类型属于 `agent/tools`。`bridge/conversation` 传递设置与展示字段，`ui/chat_ui` 编辑和显示，`ui/agent_host` 继续使用唯一 Connection。保持 Agent / Bridge 不依赖 Bevy，遵守既有单向依赖。

UI 用 BSN 构造，通过 Widgetry 公开文本和目录状态 API 操作，不直接修改内部 Editor。复用原有页面、会话核对和错误提示，不新增工作区管理后台。

源代码和依赖修改遵守 Windows x64 / PowerShell 7、Workspace 依赖统一管理、`lib.rs` 出口职责、现代 module 布局以及 unsafe / panic 禁令。登录数据目录、CredentialClient 和账号恢复路径保持不变。

## 与后续方案的关系

下一增量在本快照下执行一个真正的 Shell 命令；本增量本身只验证目录选择、校验、传递与固定，不把尚未实现的文件操作标为通过。目录快照也供后面的补丁和图像直接复用，不依赖进程会话功能。

完整路径设计见[工作环境](../../../docs/design/local-development-tools/01-working-environment.md)。本增量不引入沙箱、路径访问白名单、网络限制、审批或自动提权。工作目录只确定默认位置，不限制当前用户能访问哪些文件。

## 完成条件

在真实应用中选择两个不同的已存在目录，确认新会话取准备区新值，旧会话和重置仍使用原值；核对设置页切换、重试、Steer 与 Queue 不改变原快照。中文、空格及 Windows 路径前缀能够正确显示和保存；不存在路径、普通文件和无效路径被明确拒绝。

本增量的 UI 验证仍通过 BRP 操作 Agentelier：先取得焦点，再实际输入、选择和切页；遇到仓库已知特殊键问题使用完整 KeyboardInput 路径，不通过修改 ECS 内部状态冒充交互。验证后释放 Pointer 并确认 inactive。

按影响范围执行 Windows 目标的格式、编译或 Clippy 检查，保存真实结果。只使用现有应用、日志和调试工具，不新增测试、Benchmark、Example 或专用验证程序。不退出登录、不重建凭据、不更换数据目录。

同步当前聊天功能说明和相关会话、Bridge、UI 模块文档，准确描述目录已可选择，而实际命令能力由后续增量交付。实际修改时维护根目录临时进度记录，完成或中断状态按现有开发规范记录。
