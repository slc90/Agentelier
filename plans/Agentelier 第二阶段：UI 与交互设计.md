# Agentelier 第二阶段：UI 与交互设计

## 阶段目标

建立 Agentelier 完整的 UI 与交互体系，让用户能够自然地与助手交流、管理任务并进行协作，同时为 Agent 自主操控 UI 奠定基础。

设计过程中优先利用 `bevy_widgetry` 已有的功能，避免重复开发。

## 开发顺序

### 1. 整体 Theme 设计

确定 Agentelier 的整体视觉风格，建立统一的视觉规范，参考 GPT 的人格设定与形象设计。

### 2. 整体布局与页面信息架构

确定应用整体布局、导航体系，以及需要设计的页面。

### 3. 页面内容与交互设计

逐个确定页面的内容、功能、布局和交互方式。

### 4. 自定义控件体系

根据页面设计，建立 Agentelier 自己的控件体系，复用并扩展 bevy_widgetry 的基础控件。

### 5. System Tray

设计系统托盘，包括托盘菜单、窗口显示与隐藏、后台运行及退出行为。

### 6. Splash

设计应用启动画面、启动展示及主窗口交接体验。

### 7. Agent 自主 UI 操控

设计让 Agent 能够感知、理解和自主操作应用 UI 的机制。

## 已确定的设计边界

- 只支持中文，不考虑多语言。
- 不需要无障碍功能。
- 键盘操作与焦点管理沿用 bevy_widgetry。
- UI 缩放放在设置页面中，通过配置文件保存，启动时读取，不支持运行时修改。
- 优先复用 bevy_widgetry 已有能力，不重复实现已有功能。

## 说明

以上为当前阶段的初步开发路线，具体设计内容可以在后续讨论中扩充、调整或删减，不预先限制各阶段的设计范围。
