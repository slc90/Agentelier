# 让自定义控件支持时间驱动的演示

一些脚本控件需要连续变化，例如抛体运动、波形或算法演示。为实例提供可由 Rhai 处理的时间步/定时行为与暂停、恢复、重置、销毁契约。实际经过时间由宿主调度，与控件自身模拟状态区分；只在有需要的实例上驱动刷新，正常事件循环不因控件存在永久忙转。用户事件和时间事件在所属实例的实际顺序下更新状态、图形与文字。

Rhai 回调仍在工作者上有界执行，UI 不等待回调；复用原执行预算、通信、Winit 唤醒及取消，按照真实动画语义合并中间更新，不将每个绘图点变成独立同步请求。不把播放或运动的每帧都发给模型。暂停后状态保持，继续从对应位置推进，重置由该控件的初始定义决定。动画计算失败停止该实例的继续驱动，保留有效内容并明确反馈；其他控件不受影响。

切换 Session、卸载实例、删除和退出时停止相应计时/回调并实际回收。窗口隐藏与托盘生命周期遵循既有宿主规则，不误删 Session。存档保存有意义的模拟状态而不是 GPU 每帧内容；历史恢复不自行启动运动，除非有明确的后续用户操作。

## 验收

真实 Agent 扩展自定义抛体演示，实现开始、暂停、继续、重置；BRP 在不请求模型的情况下观察连续中间状态、质点位置及计算结果。测试快速操作、动画错误、切换与退出，不留下后台刷新、旧回执或死锁。

## 工程约束

遵循 Windows x64 / DX12、PowerShell 7 与锁定 Workspace 依赖。UI 使用 BSN、Scene / SceneList、Widgetry 公开 API；Props 仅初始化，运行期状态由 Component 与相应业务所有者维护。Agent 不依赖 Bevy、UI 或 Bridge，Bridge 不依赖 UI；现有进程内通信与权限边界不变。按实际影响进行 Cargo 检查与真实应用验证，GUI 变化用 BRP 真实输入、截图和 ECS 状态确认，结束后释放 Pointer 并核对 inactive。禁止新增测试、Benchmark、Example 代码及仅用于这些目的的依赖；未经授权不改变登录、凭据或数据目录。实施中同步受影响的当前设计文档，不提前宣称其他增量已实现。
