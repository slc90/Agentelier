# 提供具有明确统计定义的箱线图

箱线图需要四分位数、中位数、须线及异常点的明确统计含义。Scene 可接受真实样本并按确定方法计算，或接收有来源且定义完整的统计摘要。分位数方法和须线规则应在数据或显示中可识别；没有样本或异常点信息时不凭空补造。可展示多个类别分布，共用类别/数值轴、矩形、路径及点绘制能力。

零跨度、小样本、缺失、无效排序及不符合定义的分位数应处理明确；已有合法摘要与模型输入保持关联。按当前动态 Scene 机制保存定义及数据，用户改变系列选择或参数后本地更新，不把统计计算交给公式排版器。

## 验收

使用可人工核对分位数的样本、含异常点和常数的样本，核对中位数、箱体、须及点位置；BRP 检查多类别、标签、选择和历史恢复。没有原数据的摘要不出现捏造的异常点。

## 与相邻方案的关系

依赖现有坐标和绘制基础，与直方图只是统计图的相邻交付。

遵循 Windows x64 / DX12、PowerShell 7 与锁定 Workspace 依赖。UI 使用 BSN、Scene / SceneList、Widgetry 公开 API；Props 仅初始化，运行期状态由 Component 与相应业务所有者维护。Agent 不依赖 Bevy、UI 或 Bridge，Bridge 不依赖 UI；现有进程内通信与权限边界不变。按实际影响进行 Cargo 检查与真实应用验证，GUI 变化用 BRP 真实输入、截图和 ECS 状态确认，结束后释放 Pointer 并核对 inactive。禁止新增测试、Benchmark、Example 代码及仅用于这些目的的依赖；未经授权不改变登录、凭据或数据目录。实施中同步受影响的当前设计文档，不提前宣称其他增量已实现。
