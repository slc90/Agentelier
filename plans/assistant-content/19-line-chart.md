# 提供原生折线图和连续坐标轴

数据图表的输入是结构化观测，而非模型输出的屏幕像素。先建立一个实际可使用的原生折线图模板，表达数值/时间 X 轴、量值 Y 轴、多系列、名称、单位、范围、图例及缺失值。共享绘图部分负责逻辑坐标到显示区映射、轴刻度、网格、裁剪、路径、标签及主题，不预建没有用途的通用框架。Widgetry Canvas 的路径、文字等公开能力可用作绘制基础，数学坐标和轴语义仍需在自身绘图层建立。

```mermaid
flowchart LR
    Data["有序观测系列"] --> Scale["轴类型 / 范围 / 刻度"] --> Draw["Bevy 原生折线路径"]
    Data --> Draw
    Draw --> Scene["回复内图表"]
```

按明确的时间或数值顺序处理观测，多序列分别绘制。缺失或非有限值断开曲线，不补造值；单位、比例和图例与真实数据一致。图表的语义定义、数据、样式及必要的用户参数通过已建立的场景产物和状态机制保存；模型可更新现有图表，不因 Markdown 增量重建。后续图表复用真实已建立的坐标/绘制能力。

## 验收

真实 Agent 用有明确数值、时间戳、多系列及缺失区间的数据创建折线图；BRP 检查轴、刻度、图例、间隙、窄宽度和缩放，按实际数据核对坐标。更新数据、切换和重开后保持正确产物身份；非法数据反馈不使其他回复消失。

## 与相邻方案的关系

依赖可持久的原生 Scene；本项建立后续笛卡尔图表所需公共绘图基础。

设计依据：[数学与数据可视化](../../docs/design/assistant-content/05-visualization.md)、[动态 Scene](../../docs/design/assistant-content/04-dynamic-scenes.md)。

## 工程约束

遵循 Windows x64 / DX12、PowerShell 7 与锁定 Workspace 依赖。UI 使用 BSN、Scene / SceneList、Widgetry 公开 API；Props 仅初始化，运行期状态由 Component 与相应业务所有者维护。Agent 不依赖 Bevy、UI 或 Bridge，Bridge 不依赖 UI；现有进程内通信与权限边界不变。按实际影响进行 Cargo 检查与真实应用验证，GUI 变化用 BRP 真实输入、截图和 ECS 状态确认，结束后释放 Pointer 并核对 inactive。禁止新增测试、Benchmark、Example 代码及仅用于这些目的的依赖；未经授权不改变登录、凭据或数据目录。实施中同步受影响的当前设计文档，不提前宣称其他增量已实现。
