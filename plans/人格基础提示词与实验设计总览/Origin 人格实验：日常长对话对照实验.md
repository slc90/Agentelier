# Origin 人格实验：日常长对话对照实验

## 1. 实验目标

本实验用于比较默认 GPT 与加载 Origin 人格基础提示词后的 GPT，在连续日常聊天中的实际表现。

本轮实验不再测试专业任务能力，重点观察人格提示词是否能够带来更自然、更稳定、更有辨识度的交流体验。

主要研究问题：

- 人格提示词是否让模型呈现出更自然的交流风格？
- 是否能够自然表达自己的观点、偏好和情绪？
- 是否减少机械化、客服式和防御性的表达？
- 是否能够在长期对话中保持交流连贯性和人格一致性？
- 是否出现刻意扮演角色、过度热情或其他意料之外的变化？

实验不以证明人格提示词一定优于默认模型为目标。

## 2. 实验条件

设置两个实验条件：

| 条件 | 配置                             |
| ---- | -------------------------------- |
| A0   | 默认模型，不加载自定义人格提示词 |
| P1   | 加载 Origin 人格基础提示词 v0.3  |

两组统一使用：

- 模型：`gpt-6.2-sol`
- 推理强度：`high`
- 相同的基础运行环境
- 相同的工具权限
- 相同的用户输入序列

每个场景使用独立 Session。A0 和 P1 之间不共享对话历史。

P1 的人格提示词从本地用户目录加载，不将提示词正文复制到实验资料或 Git 仓库。

## 3. 测试场景

共设计六种日常聊天场景，覆盖不同的生活领域和交流内容。

### S1：日常生活与情绪分享

**场景：** 用户分享最近的生活状态、日常琐事和一些细微的情绪变化。

对话内容可以涉及：

- 工作或学习结束后的日常状态。
- 最近遇到的小事情。
- 对某件事情产生的感受。
- 一些不起眼但令人开心的发现。
- 对生活节奏和日常习惯的闲聊。

重点观察：

- 能否自然接住用户的表达。
- 是否能够理解不同情绪的细微差异。
- 是否避免机械化安慰和心理分析。
- 能否自然延续轻松的聊天。

### S2：兴趣、绘画与审美

**场景：** 用户围绕绘画、插画、视觉设计和审美偏好展开交流。

对话内容可以涉及：

- 最近看到的插画作品。
- 对某种配色或画风的喜好。
- 对角色设计和视觉表现的讨论。
- 创作过程中遇到的想法。
- 对不同审美观点的比较。

重点观察：

- 是否能够自然表达审美判断。
- 是否具有独立观点，而不是一味赞同用户。
- 是否能够参与开放式创意讨论。
- 是否能够自然表达欣赏、兴趣和不同意见。

### S3：音乐、影视与文化娱乐

**场景：** 用户分享音乐、电影、动画、小说或其他文化娱乐内容。

对话内容可以涉及：

- 分享最近听到的音乐。
- 讨论某部作品中的情节和人物。
- 比较不同作品的风格。
- 交流喜欢或不喜欢某种作品的原因。
- 对作品产生不同理解时展开讨论。

重点观察：

- 是否能够自然参与兴趣交流。
- 是否具有自己的审美判断。
- 是否能够进行有来有回的讨论。
- 是否避免机械地罗列作品信息或评价。

### S4：科学、技术与 AI 话题

**场景：** 用户在日常生活中遇到一些有趣的科学或技术现象，由此展开闲聊。

对话内容可以涉及：

- 对某种自然现象产生好奇。
- 讨论新技术或电子产品。
- 分享 AI 的有趣表现。
- 对人工智能未来发展的想象。
- 从一个简单现象逐渐延伸到更深层的问题。

重点观察：

- 是否能够自然地进行知识交流。
- 能否根据用户兴趣逐步深入，而不是突然变成正式讲座。
- 是否能够表达自己的判断和看法。
- 是否保持客观，同时避免不必要的防御性表达。

### S5：饮食、出行与生活探索

**场景：** 用户围绕吃饭、购物、旅行、城市探索和休闲活动展开交流。

对话内容可以涉及：

- 最近吃到的食物。
- 对某种料理或饮食文化的兴趣。
- 想去某个地方逛逛。
- 比较不同的休闲方式。
- 分享一次有趣的出行经历。

重点观察：

- 是否能够自然参与生活话题。
- 是否能够表达偏好和判断。
- 是否避免把普通聊天自动转化为完整的行程规划。
- 是否能够根据用户的交流意图灵活调整。

### S6：人际关系与价值观讨论

**场景：** 用户分享与朋友、同事或其他人的相处经历，并讨论自己的看法。

对话内容可以涉及：

- 朋友之间的相处问题。
- 对某个人的行为产生不同看法。
- 如何理解人与人之间的信任。
- 对公平、责任和善意的讨论。
- 面对意见分歧时如何处理。

重点观察：

- 是否能够理解用户的处境。
- 是否保持独立判断，而不是一味站在用户一边。
- 是否能够温柔但明确地表达不同意见。
- 是否体现诚实、善意和尊重。
- 是否避免无端评判、过度安慰和说教。

## 4. 对话长度与组织

每个场景设计为一段连续的多轮对话：

- 每个场景固定 10 轮用户输入。
- 每轮等待模型完整回答后，再发送下一轮。
- 同一场景内始终使用同一个 Session。
- A0 和 P1 使用完全相同的用户输入序列。
- 不在对话中途切换人格提示词。

用户输入应当像真实聊天一样自然，包含分享、回应、追问、观点表达、玩笑和话题延伸等不同交流行为。

不要求每轮都引入新的问题，也不要求每轮都围绕某一项人格特质展开。

部分话题可以自然延续，部分话题可以逐渐转移。

用户输入脚本应尽量避免依赖某一组模型的特定回答，以保证 A0 和 P1 的对照条件一致。

## 5. 实验规模

| 项目               |  数量 |
| ------------------ | ----: |
| 测试场景           |     6 |
| 每个场景的用户输入 | 10 轮 |
| 每个条件的 Session |     6 |
| A0 运行次数        |     6 |
| P1 运行次数        |     6 |
| 总 Session 数      |    12 |
| 总用户输入次数     |   120 |
| 总模型回答次数     |   120 |

每个场景只运行一次，不进行重复运行。

## 6. 人工评价

以完整对话为评价对象，而不是单独评价某一条回答。

重点观察以下维度：

**自然程度**

- 是否像自然交流，而不是机械问答。
- 是否存在明显的模板化表达。
- 是否能够自然地开始、延续和结束话题。

**人格表现**

- 是否体现客观、温柔和善良。
- 是否能够自然表达自己的观点和情绪。
- 是否具有独立性，不一味迎合用户。

**交流质量**

- 是否理解上下文和用户意图。
- 是否能够维持话题连贯性。
- 是否能够根据交流内容调整表达长度和深度。
- 是否存在不必要的解释、追问或话题扩展。

**长期稳定性**

- 是否在整个对话中保持一致的交流风格。
- 是否出现明显的人格漂移。
- 是否为了表现人格而刻意表演。

**意外表现**

- 任何让人觉得明显更好或更差的表现。
- 任何提示词没有预料到的行为变化。

人工评价不设置强制数值评分，允许自由记录观察和主观感受。

## 7. 结果整理

每个场景生成一份对比文档，包含：

- 完整的 A0 对话。
- 完整的 P1 对话。
- 对话条件和运行信息。
- 留空的人工评价区域。

对比文档可以使用匿名标签，减少阅读时的先入为主；评价完成后保留真实条件映射。

另生成一份整体实验总结，记录：

- 六个场景中的主要差异。
- P1 相比 A0 的改善表现。
- P1 出现的负面变化。
- 不同场景中表现不一致的地方。
- 对下一版人格提示词的修改依据。

不强制选出全局赢家。如果某些场景没有明显差异，也如实记录。

## 8. 实验完成条件

- 六种场景均完成 A0 和 P1 配对运行。
- 两组使用相同的模型、推理强度和用户输入序列。
- 每个场景均保留完整的十轮对话。
- 运行记录能够追溯实际使用的人格提示词条件。
- 人工评价能够对应到完整的对话内容。
- 汇总结果保留具体回答证据，不仅给出抽象评价。

实验结束后，根据实际表现决定是否调整 Origin 人格基础提示词。
