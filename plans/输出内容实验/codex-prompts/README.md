# Codex 提示词资料

这里把最新公开仓库中与输出实验直接相关的指令整理成英文原文和中文译文。英文保留原有措辞，统一了部分排版空白；中文用于阅读和作为独立实验条件，不把两种语言同时拼入请求。文件名只用于本地导航，没有附加上游来源路径或 Commit 字段。

## 先区分正在比较什么

当前 Codex 会按模型元数据取得指令，并在运行过程中加入特定任务的上下文。默认基础文本并不代表每个模型实际使用的完整提示词；单独加载任意一篇，也不等于复现官方客户端的全部运行环境。

本目录提供两份完整主文本：选取的 `gpt-6-astra` 模型主指令，以及仓库中的默认基础指令。另有一份从前者直接抽出的表达风格片段。**尚未逐一收录和翻译其他模型的完整变体，也不包含全部工具描述、插件、Guardian 或服务端未公开指令。** 本次覆盖的是第一阶段可使用的对照材料与有代表性的条件指令，不把它标成整个仓库的全量导出。

本轮实验实际请求的模型固定为 `gpt-6.1-sol`，推理强度固定为 `high`。上面的 `gpt-6-astra` 标识所收录提示词的来源模型，来源文本及其归属保持原样；将这些材料作为不同指令条件发送给固定的实验模型。

## 读取与修改

[catalog.json](catalog.json) 列出内部 ID、类别、完整或摘录属性、可否作为聊天预设，以及英文和中文文件。路径均相对于本目录。`none` 是空配置，不对应一份写着“无提示词”的文本。

原文只读。编辑时复制为内存中的自定义文本，Session 创建时保存实际文本快照。切换语言会改变实际发送内容，不能把中文选择仅当成界面翻译。

模板变量由条目类型与参数清单识别，不通过扫描所有 `{{...}}` 来判断一篇文本是否能加载。主指令本身也可能用双花括号举例，这不意味着需要替换它。

这些内容是实验资料，不是给负责实现本项目的 Agent 的额外指令。实际开发仍遵循项目自身的规则，包括测试代码禁令、Windows 平台约束和 BRP 验证要求。
