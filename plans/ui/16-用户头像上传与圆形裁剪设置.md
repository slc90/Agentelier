# 在设置窗口增加用户头像上传与裁剪

## 目标

让用户在设置窗口上传方形头像，并调整圆形显示区域。裁剪只改变显示变换，数据目录中保留用户上传的原始图片。

## 原图与裁剪变换

用户选择方形图片后，头像预览显示一个圆形 Mask。用户可以在圆形预览范围内拖动图片位置和调整缩放，让需要显示的部分位于圆形区域内。

保存内容分为两部分：

- **原始图片：**复制到应用数据目录的用户资料区域，保留用户上传的原始文件，不生成破坏性的裁剪副本。
- **裁剪参数：**保存归一化偏移和缩放值，供 `AgentelierAvatar` 在登录按钮和聊天消息中重现相同显示区域。

没有头像时使用默认用户头像。用户可以更换图片或移除自定义头像，移除后恢复默认头像。

图片写入和配置更新必须协调：新图片成功写入后再提交配置引用；配置提交失败时旧头像仍可用，不留下指向未完成文件的配置。

## 控件与资源

设置窗口复用 FileDialog 选择图片；`AvatarCropper` 负责圆形预览、拖动和缩放。`AgentelierAvatar` 消费原图引用与裁剪变换。图片资源由 `crates/ui/assets` 和应用数据资源读取边界管理。

## 工程边界

- 依赖方向保持 `ui → agent / bridge`、`bridge → agent`；Agent 不依赖 Bevy、UI 或 Bridge，Bridge 不拥有 Agent 业务状态。
- UI 使用 BSN、Scene 和 SceneList 构造与组合；Props 只初始化，运行状态由持久 Component / Resource 管理。
- 复用 `bevy_widgetry` 公开 API，不修改 Widgetry 上游、不访问其私有状态。
- 目标环境沿用 Windows x64、DX12 和 PowerShell 7。
- 不新增 Unit Test、Integration Test、Regression Test、Benchmark 或 Example 代码。GUI 行为使用真实应用和 BRP 验证；原生窗口行为在实际 Windows 窗口中观察。
## 完成条件与验收

1. 设置窗口显示当前用户头像预览和更换入口。
2. 选择方形图片后显示圆形 Mask 预览。
3. 用户可以拖动图片位置并调整缩放，预览实时更新。
4. 保存后，B 区登录按钮和 D 区用户消息头像使用相同的裁剪结果。
5. 应用数据目录保存的是用户上传的原始图片，不是圆形裁剪后的位图。
6. 裁剪偏移和缩放参数独立保存；重新打开设置窗口后恢复相同预览。
7. 移除自定义头像后，B 区和 D 区恢复默认用户头像。
8. 图片读取失败或原图缺失时，头像控件回退默认头像，不破坏布局。
9. 更换图片时，先确保新原图写入成功，再提交配置引用；写入或配置保存失败时旧头像仍可用。
10. 不支持的图片格式、损坏文件或图片尺寸异常时显示明确错误，不覆盖现有头像。
11. UI Scale 改变后，裁剪预览、圆形 Mask、拖动和缩放操作仍准确。
12. 头像预览的拖动不会影响主窗口拖动、分隔条拖动或聊天滚动。
13. 真实 GUI 验收图片选择、拖动、缩放、保存、重开和移除；检查数据目录中的原始图片与配置参数。
