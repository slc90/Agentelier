# 交付 B 区登录入口与手动授权窗口

## 目标

完成登录按钮的头像展示、手动复制授权链接窗口，以及已登录时的右键登出菜单。

## 交互规则

登录按钮使用圆形 AgentelierButton 和 AgentelierAvatar：

- 未登录：默认用户头像。
- 已登录且设置头像：显示用户头像。
- 已登录但没有头像：仍显示默认用户头像。

未登录时左键点击，弹出类似 Widgetry MessageBox 的授权窗口，显示浏览器授权链接并允许复制。应用不自动打开系统浏览器，用户自行粘贴到浏览器完成授权。

已登录时左键点击无操作。已登录时右键点击菜单只有“登出”一项；未登录时右键点击无操作。

登录和登出由 `agent/login`、`agent/account` 与现有 Bridge 流程管理。UI 不读取、显示或写入 OAuth Token。

## Widgetry 复用

AgentelierButton、AgentelierAvatar、MessageBox / Window、ReadOnlyTextField 和公开 Popup / 副键输入能力。右键菜单只用于登录按钮，不成为所有按钮的通用右键行为。

## 工程边界

- 依赖方向保持 `ui → agent / bridge`、`bridge → agent`；Agent 不依赖 Bevy、UI 或 Bridge，Bridge 不拥有 Agent 业务状态。
- UI 使用 BSN、Scene 和 SceneList 构造与组合；Props 只初始化，运行状态由持久 Component / Resource 管理。
- 复用 `bevy_widgetry` 公开 API，不修改 Widgetry 上游、不访问其私有状态。
- 目标环境沿用 Windows x64、DX12 和 PowerShell 7。
- 不新增 Unit Test、Integration Test、Regression Test、Benchmark 或 Example 代码。GUI 行为使用真实应用和 BRP 验证；原生窗口行为在实际 Windows 窗口中观察。
## 完成条件与验收

1. 未登录时显示默认用户头像。
2. 已登录且有用户头像时显示配置头像；没有头像或图片加载失败时回退默认头像。
3. 未登录左键打开授权窗口，显示当前 Login Prompt 返回的链接。
4. 授权链接可选中并复制；复制内容与 Agent 返回值一致。
5. 点击链接文本不会自动启动系统浏览器。
6. 已登录左键点击没有任何动作，不打开窗口、不刷新账号、不登出。
7. 已登录右键只显示“登出”一项。
8. 未登录右键不显示菜单、不触发动作。
9. 登出通过 Account 命令提交；只有收到真实回执后才更新登录按钮状态。
10. 登出失败时保持真实账号状态，不提前清除头像或显示未登录。
11. 授权链接为空、过期或获取失败时显示明确错误，不展示旧链接冒充有效链接。
12. UI 与日志不出现 Access Token、Refresh Token 或凭据内容。
13. GUI 验收左键、右键、窗口打开和关闭；账号状态通过真实 Agent 回执核对。
14. 验收期间遵守账号状态保护，不主动登出、重新登录或清理凭据；需要此类操作时等待用户授权。
