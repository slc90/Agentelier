# 交付只读记忆摘要与专用聊天窗口

## 目标

完成 B 区记忆管理入口，展示已发布的长期记忆摘要和详细来源，并通过专用 Session 与助手交流记忆查询、添加、纠正和忘记请求。

## 窗口结构

- 顶部：标题“记忆摘要”和最近更新时间。
- 中间：已发布摘要、可展开的详细记录和来源，以及专用 Session 的聊天内容。
- 底部：与助手交流的输入框。

摘要、详细记录和来源只读，可以选择和复制。窗口不提供手动编辑器、单条删除、重置长期记忆或空的更多菜单。

记忆聊天使用上一增量创建的专用 Session，不使用当前 C 区 Session。该 Session 在当前程序运行期间唯一，下一次启动创建新的 Session。

## 记忆修订语义

聊天框支持用户明确表达记住某项信息、纠正或更新已有记忆、忘记某项信息，以及查询当前记忆。

普通提问只查询和回答，不自动触发记忆修改。显式 Remember / Correct / Forget 仍由 `crates/agent/memory` 的修订能力完成；UI 不直接修改 Markdown 或 SQLite。

修订保存与摘要发布是两个不同阶段。修订已保存、等待整合时显示等待状态；只有新摘要发布成功后才更新摘要正文和更新时间。

## Agent / Bridge 影响

- `crates/agent/memory`：复用已发布摘要、详情、来源查询和显式修订能力。
- `crates/agent/conversation`：提供专用 Session / Turn 身份和真实用户语句。
- `crates/agent/runtime`：路由专用 Session 的聊天和 Memory 工具执行。
- `crates/bridge/conversation` / `connection`：投影安全摘要、详情和修订状态。
- UI 只显示 Agent 已发布数据，不成为 Memory 数据所有者。

## Widgetry 复用

Window、ReadOnlyTextField / Text、Collapsible、ScrollArea、TextField 和 AgentelierButton。聊天内容复用 ConversationView 的消息呈现规则；输入使用专用 Session，不显示普通 D 区模型选择器。

## 工程边界

- 依赖方向保持 `ui → agent / bridge`、`bridge → agent`；Agent 不依赖 Bevy、UI 或 Bridge，Bridge 不拥有 Agent 业务状态。
- UI 使用 BSN、Scene 和 SceneList 构造与组合；Props 只初始化，运行状态由持久 Component / Resource 管理。
- 复用 `bevy_widgetry` 公开 API，不修改 Widgetry 上游、不访问其私有状态。
- 目标环境沿用 Windows x64、DX12 和 PowerShell 7。
- 不新增 Unit Test、Integration Test、Regression Test、Benchmark 或 Example 代码。GUI 行为使用真实应用和 BRP 验证；原生窗口行为在实际 Windows 窗口中观察。
## 完成条件与验收

1. 点击 B 区记忆按钮打开记忆管理窗口。
2. 顶部显示“记忆摘要”和真实最近更新时间。
3. 中间显示已发布摘要，内容与 Agent Memory 返回一致。
4. 详细记录和来源可以展开、折叠、选择和复制，但不能编辑或删除。
5. 窗口没有更多菜单、重置长期记忆、单条删除或手动编辑器。
6. 窗口聊天显示专用 Session 的消息；关闭和重开窗口后仍使用本次进程同一 Session。
7. 普通 C 区 Session 切换不改变记忆窗口的专用 Session。
8. 用户明确要求记住时，消息通过专用 Session 提交，Agent 收到真实用户原话后创建修订。
9. 用户明确纠正或忘记时，使用现有 Correct / Forget 授权规则；UI 不直接删除或覆盖记忆文件。
10. 用户询问“你记得什么”时只查询和回答，不创建 Remember / Correct / Forget 修订。
11. 普通聊天中的事实陈述没有明确记忆意图时，不自动触发修订。
12. 修订保存成功但整合未完成时，显示等待整合；不提前更新摘要和更新时间。
13. 新摘要发布成功后更新摘要正文与更新时间；发布失败时继续显示上一次有效摘要。
14. Memory 数据库不可用、来源损坏、修订被拒绝或摘要发布失败时显示真实错误，旧摘要仍可读。
15. 关闭和重开窗口不会把未提交草稿伪装成已发布记忆。
16. 记忆详情只显示安全投影，不暴露数据库路径、凭据或未脱敏的原始工具输出。
17. 通过 BRP 验收窗口打开、滚动、详情展开、文本选择和聊天输入；Agent 侧核对修订保存、后台整合和摘要发布。
18. 不增加记忆重置、手动编辑或单条删除入口。
