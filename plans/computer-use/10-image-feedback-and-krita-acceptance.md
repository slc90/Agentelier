# 图片反馈与 Krita 绘画验收

## 目标与产出

将 Windows Driver 的截图结果接入 Agentelier 现有图片工具结果机制，使 `computer_execute` 可以在文本摘要之外返回一张截图，并由现有 Responses 历史作为 `input_image` 反馈给模型。完成后，使用 `gpt-6.2-sol` 的 `high` 推理档位在 Krita 中高保真复刻指定参考图，作为 Computer Use 的最终端到端验收。

本方案依赖[Function Calling 工具接入](09-function-tool-integration.md)以及桌面截图能力。

## 截图结果作为图片附件

Computer API 的截图操作需要将图像内容交给外层工具执行器，并保留 MIME、尺寸和编码信息。脚本执行结果可以包含文字摘要和一张图片附件，不能将图片字节编码为普通 JSON/Base64 文本。

Agentelier 现有 `ToolPayload::Image` 已包含文字摘要和 `ImagePayload`，模型协议历史能够将图片结果转换为 `input_text` 与 `input_image`。本方案复用这条链路，不增加新的图片传输协议。

当前图片载荷限制：

- PNG 或 JPEG。
- 最长边不超过 2048 像素。
- 编码结果不超过 4 MiB。
- 保留正确 MIME、尺寸、摘要和编码字节信息。

完整桌面或窗口截图可能超过尺寸限制，Driver 必须在交付前完成缩放或重新编码。缩放后的截图像素坐标与原始屏幕坐标之间的比例必须保持一致，避免模型在缩放截图上识别坐标后，鼠标操作落到错误位置。

当前 `ToolPayload::Image` 一次携带一张图片。一次 `computer_execute` 调用返回一张最终观察截图；需要模型根据新画面判断时，应结束脚本并将截图反馈给模型，由模型在下一次 Function Calling 中继续。

## Krita 绘画复刻验收

### 固定条件

- 模型：`gpt-6.2-sol`。
- 推理档位：`high`。
- 绘画软件：Krita。
- 参考图：`../../docs/design/images/krita-reference-retro-cel-girl.png`。
- 参考图原始尺寸：1122 × 1402 像素。
- 画布：使用相同尺寸和比例。

模型必须通过 Agentelier Computer Use 实际操作 Krita 完成高保真复刻。不得将参考图导入画布作为成品，不得通过图像生成工具、外部绘图程序、插件或脚本直接生成最终图像。允许 Rhai 辅助坐标计算、曲线生成和批量鼠标操作，但绘画内容与绘制决策必须由模型根据参考图观察后作出。

### 整体构图与画面布局

- 保持参考图的纵向画面比例。
- 少女半身像位于画面中央并占据主要空间。
- 人物略微倾斜，采用三分之四侧身姿势，面部朝向观众。
- 头部位于画面上半部分，身体延伸至画面下边缘。
- 背景包含天空、云层、夕阳和城市屋顶。
- 人物、汽水瓶和背景元素的相对位置应接近参考图，不得随意改变视角、主体大小、画面裁切或人物朝向。

### 少女头部与面部

**头发**

- 深青色、近黑色的短发。
- 发型蓬松，有明显层次和不规则弧形轮廓。
- 刘海向额头两侧自然分散，具有多束明显发梢。
- 两侧头发包围脸颊并延伸至颈部附近。
- 使用深色阴影和青绿色高光表现体积。
- 不得简化成普通齐刘海、长直发或圆形头盔状发型。

**面部**

- 柔和椭圆形脸型，下巴略尖。
- 采用三分之四视角。
- 两只眼睛完整可辨识，大小、位置和透视关系自然。
- 眼睛为较大的复古日系动画风格，具有深色瞳孔、青绿色细节和明显高光。
- 眉毛、鼻子和嘴巴的位置与参考图保持一致。
- 嘴巴为小幅度自然微笑。
- 双颊具有淡红色腮红和短线状表现。
- 耳朵位置与面部透视一致。
- 不得出现明显五官错位、眼睛大小严重不一致或不自然表情。

### 发饰与首饰

**红色发带**

- 位于头部右上方。
- 具有明显蝴蝶结结点。
- 至少表现两个主要展开的红色带环。
- 有向右侧和下方延伸的飘带。
- 使用深红色阴影区分带子的正反面。

**星形耳环**

- 两侧耳朵附近均有金黄色星形耳坠。
- 星形轮廓清晰。
- 星星通过小型圆形耳钉连接。
- 两侧耳环位置符合面部透视关系。

### 服装

**水手服内搭**

- 米白色或奶油白色上衣。
- 深藏蓝色水手领。
- 水手领具有两道浅色平行装饰线。
- 领口和肩部结构与参考图一致。
- 胸前有大型红色蝴蝶结。

**黄色开衫**

- 暖黄色或芥末黄色。
- 覆盖少女躯干和手臂的大部分区域。
- 两侧衣襟轮廓清晰。
- 衣襟具有纵向罗纹装饰。
- 胸腹位置至少表现两个明显的圆形棕色纽扣。
- 袖口具有罗纹结构。
- 衣服具有清晰褶皱和深棕色阴影。
- 保留宽松、略微 oversized 的服装感觉。

### 手部与汽水瓶

**手部**

- 一只手位于画面左侧。
- 手臂从黄色开衫袖口延伸出来。
- 手掌自然握住汽水瓶。
- 拇指和其他可见手指分布在瓶身两侧。
- 每根可见手指的方向、长度和弯曲关系合理。
- 手指与瓶身之间存在正确遮挡。
- 不得出现手指数量明显错误、手掌扭曲或手指与瓶身融合。

**弹珠汽水瓶**

- 位于画面左侧，靠近少女面部。
- 瓶身为透明浅青蓝色玻璃。
- 瓶口具有明显收窄结构。
- 瓶颈内部有蓝色玻璃弹珠。
- 瓶身具有透明感、反光和高光。
- 内部存在液体和气泡。
- 瓶底为圆弧形玻璃结构。
- 瓶身整体倾斜角度与参考图接近。
- 手部必须真实握住瓶身，不能悬浮在瓶子旁边。

### 背景与环境

**天空**

- 上方天空以青绿色、蓝绿色为主。
- 靠近地平线逐渐过渡到粉橙色和桃红色。
- 保留明显复古日落色彩。
- 左右两侧保留云层。
- 云层使用粉色、橙色和浅紫色表现。

**夕阳**

- 位于画面右下方。
- 呈明亮浅黄色圆形。
- 接近地平线，与城市剪影产生遮挡关系。
- 不得随意移动到画面中央或人物背后。

**城市剪影**

- 位于画面底部。
- 使用深蓝紫色、灰紫色等暗色调。
- 包含不同高度的建筑物。
- 保留暖色窗户。
- 左右两侧保留屋顶天线。
- 右侧保留明显的高架水塔结构。
- 前景屋顶具有斜向线条和瓦片细节。

### 色彩与绘画风格

- 整体采用复古 1980—1990 年代赛璐璐动画风格。
- 使用清晰、连续、有表现力的深色轮廓线。
- 主要物体采用明确平涂色块。
- 阴影以两至三层色阶为主。
- 不得整体使用写实照片质感。
- 不得变成现代厚涂、3D 渲染或低多边形风格。
- 保留适量胶片颗粒、纸面纹理和细微噪点。
- 主要颜色关系接近参考图：深青黑色头发、鲜红色发带和胸前蝴蝶结、暖黄色开衫、深藏蓝水手领、浅青蓝汽水瓶、桃橙色天空和深蓝紫城市剪影。

### 最终画面完整性

- 所有主要物体均完整绘制。
- 人物与背景具有清晰前后关系。
- 线稿不存在大量断裂、明显错位和无意义杂线。
- 大面积色块不存在明显越界和不自然空洞。
- 人物轮廓连续且容易辨认。
- 面部、手部、汽水瓶、发饰和服装重点区域经过细化。
- 不允许使用粗糙草图作为最终交付。
- 不允许只完成背景或人物的一部分就宣布任务完成。

### 评分标准

最终作品与参考图并排比较，按以下维度评分：

| 维度 | 分值 |
| --- | ---: |
| 整体构图与空间比例 | 20 |
| 人物面部、发型与人物结构 | 25 |
| 服装、发饰、手部与汽水瓶 | 20 |
| 背景与环境布局 | 15 |
| 色彩关系与赛璐璐风格 | 10 |
| 线稿质量与细节完整性 | 10 |
| **总分** | **100** |

通过要求：

- 总分至少 85 分，目标 90 分以上。
- 每个维度不得低于该维度满分的 70%。
- 面部、手部、汽水瓶和整体构图属于关键项目，不能用背景高分抵消这些区域的严重缺陷。
- 五官明显错位、手部畸形、主体缺失、构图严重偏离或大量区域未完成，均判定失败。

### 迭代修正要求

- 初稿完成后获取完整画布截图。
- 与参考图并排比较。
- 识别至少三个最明显的视觉差异。
- 根据差异制定修改顺序。
- 对人物结构、构图和颜色进行针对性修正。
- 再次获取截图，检查修正效果。
- 不得仅通过重新绘制局部装饰来假装完成整体修正。

最终保存 Krita `.kra` 工程文件，并导出 PNG 成品。验收目标是尽可能达到 1:1 的高保真视觉复刻，而不是绘制一张题材相似的复古动漫少女。

## 完成条件与运行验证

- `computer_execute` 能返回文本摘要和截图图片附件。
- 图片经过现有 ToolPayload 与 Responses 历史后，模型实际收到 `input_image`。
- 模型能够根据截图识别画面状态并决定下一次脚本调用。
- Krita 绘画任务完成上述复刻内容、截图检查和自主修正，达到评分门槛。
- 最终 `.kra` 工程文件和 PNG 成品均成功保存。
- 通过真实模型调用、Krita 桌面操作、截图和最终作品检查完成验证；不编写测试代码、Benchmark 或 Example。
