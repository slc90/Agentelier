# OpenAI API 月度额度使用规划：GPT-Live 1.1 与 Decisions API

## 1. 资源定位

每月获得的 $100 OpenAI API Credit 不用于重复承担 Codex 订阅额度已经能够满足的日常开发、文本推理和图片生成任务，而是主要用于扩展订阅调用方式无法直接覆盖的专用 API 能力。

本计划重点关注两项服务：

- **GPT-Live 1.1**：实时语音交互，提供自然、低延迟的双向语音能力。
- **Decisions API**：快速、低成本的结构化判断，适合实时分类、选择、条件判断和评分。

两者可以独立使用，也可以结合使用，让语音交互具备实时决策能力。

---

## 2. GPT-Live 1.1：实时语音交互

### 能力介绍

GPT-Live 1.1 是 OpenAI 提供的全双工语音模型（Full-duplex）。

与传统的语音转文字、文本模型处理、文字转语音流程不同，它可以直接处理连续的语音输入并生成语音输出。

主要能力：

- 实时语音输入和输出。
- 支持用户与模型同时说话。
- 支持自然的打断和对话接续。
- 支持多语言语音交互。
- 支持 Function Calling。
- 可以将复杂任务委托给后端模型或 Agent 处理。

GPT-Live 主要负责实时对话，后端模型或 Agent 负责复杂推理、工具调用和任务执行。两者可以使用不同的模型。

连接方式包括 WebRTC、WebSocket 和 SIP。其中 WebRTC 适合浏览器、移动端及服务器应用。

### 适用场景

**实时语音助手**

用户直接通过麦克风与助手交流，不必每次先完成语音转写再发送文本请求。

**语音控制**

通过自然语言发出指令，例如控制程序、查询运行状态、执行指定操作。

**交互式游戏与应用**

为游戏或桌面应用提供语音交互能力，让用户可以自然地与应用中的智能角色或助手交流。

**实时任务协作**

用户在描述任务时，后台可以同步执行检索、推理和工具操作，GPT-Live 则继续维持自然对话，并在任务完成后反馈结果。

### 费用

GPT-Live 1.1 按语音会话持续时间收费，精确到秒，不会强制向上取整到整分钟。

| 状态            |         价格 |
| --------------- | -----------: |
| Active（活跃）  | $0.05 / 分钟 |
| Standby（待机） | $0.02 / 分钟 |

Standby 价格适用于 WebRTC 会话中推理暂停的状态，并不是所有静音时间都会自动按照待机价格计算。

**活跃状态费用估算：**

| 使用时间 |   费用 |
| -------- | -----: |
| 1 分钟   |  $0.05 |
| 10 分钟  |  $0.50 |
| 30 分钟  |  $1.50 |
| 1 小时   |  $3.00 |
| 10 小时  | $30.00 |
| 20 小时  | $60.00 |

以每月 $100 API Credit 计算：

- 全部处于 Active：约 33 小时 20 分钟。
- 全部处于 Standby：约 83 小时 20 分钟。

以上为单一状态下的理论值，实际会根据活跃和待机时间的比例变化。

**额外费用：**

GPT-Live 的语音会话费用不包含后端模型和工具调用费用。

如果会话需要调用 Responses API、其他模型或工具，这些服务会按照各自的价格单独计费。

## 3. Decisions API：快速结构化决策

### 能力介绍

Decisions API 使用 `gpt-6-luna`，专门处理明确、结构化的判断任务。

它不以生成完整的自然语言回答为目标，而是根据输入信息和预先定义的问题，返回程序可以直接使用的判断结果。

目前提供三种决策类型：

**Predicate（条件判断）**

判断某个条件是否成立，返回对应的概率。

例如：

- 当前请求是否需要调用工具？
- 当前场景是否存在异常？
- 用户是否明确要求修改项目？

**Choice（选项选择）**

从给定选项中选择最合适的结果，同时返回各选项的概率分布。

例如：

- 应该调用哪个工具？
- 用户请求属于哪种类型？
- 应该选择哪一种处理路径？

**Score（评分）**

按照预先定义的有序等级进行评分。

例如：

- Bug 的严重程度。
- 任务的紧急程度。
- 当前状态的风险等级。

### 输入与调用特点

- 支持文本输入。
- 支持 JSON 结构化数据。
- 支持图片输入。
- 支持一次请求提出多个独立问题。
- 每次请求最多支持 400 个问题。
- 返回结构化结果，包括判断结果、概率分布和 Confidence 等信息。

Decisions 适合处理可以明确描述判断标准的任务，不适合替代需要复杂推理和长篇内容生成的通用模型。

### 适用场景

**实时请求分类**

根据用户请求判断应该进入哪条处理路径。

**工具选择**

从多个工具中选择最适合当前请求的工具。

**条件检查**

快速判断某个条件是否成立，决定是否继续执行后续任务。

**风险与严重程度评分**

对检测结果进行分级，为后续处理提供依据。

**图片内容判断**

根据图片判断是否存在特定对象、状态或异常。

### 费用

Decisions API 只对输入 Token 收费，不收取输出 Token 费用。

| 项目            | 价格 / 100 万 Token |
| --------------- | ------------------: |
| 普通输入        |               $0.10 |
| 缓存命中输入    |               $0.01 |
| 30 分钟缓存写入 |              $0.125 |
| 输出 Token      |                免费 |

超长上下文和特定区域处理可能产生额外费用。

**普通输入成本估算：**

| 每次输入 Token | 单次费用 | $100 可支持次数 |
| -------------- | -------: | --------------: |
| 500            | $0.00005 |        200 万次 |
| 1,000          |  $0.0001 |        100 万次 |
| 2,000          |  $0.0002 |         50 万次 |
| 5,000          |  $0.0005 |         20 万次 |
| 10,000         |   $0.001 |         10 万次 |

因此，Decisions API 可以承担相当高频的轻量判断任务，而不需要消耗大量预算。

需要注意：返回的概率和 Confidence 是模型估计值，不等于实际准确率。应当使用真实样本进行测试，并根据误判成本确定决策阈值。

## 4. GPT-Live 与 Decisions 的联合使用

这两项服务可以形成互补关系。

GPT-Live 负责理解语音对话、维持交互和生成语音；Decisions 负责快速判断当前语音请求应该触发什么动作。

OpenAI 已经提供原生集成方式，GPT-Live 可以直接调用 Decisions，不必先经过应用程序再发起一次独立请求。

也可以在用户输入的转写内容或 GPT-Live 输出的转写内容到达时触发决策。

例如：

1. 用户通过语音提出请求。
2. GPT-Live 实时接收并理解对话。
3. Decisions 判断请求类型、目标动作及是否需要调用后端。
4. 应用程序根据决策结果执行对应操作。
5. GPT-Live 将执行结果以自然语音反馈给用户。

这种方式特别适合需要快速响应的交互场景。

## 5. 每月 $100 API Credit 的使用策略

两项服务的费用结构差异较大，因此不需要强行平均分配预算。

| 服务          | 预算定位         | 使用策略                 |
| ------------- | ---------------- | ------------------------ |
| Decisions API | 低成本、高频使用 | 可以承担大量实时判断任务 |
| GPT-Live 1.1  | 主要预算消耗项   | 按需启动，控制会话时长   |

一个参考性的月度使用方案：

| 项目                          |     预算 |
| ----------------------------- | -------: |
| GPT-Live 活跃会话 20 小时     |      $60 |
| Decisions 普通输入 1 亿 Token |      $10 |
| 剩余预算                      |      $30 |
| **合计**                      | **$100** |

这只是一个预算示例，不是固定分配比例。

Decisions 的实际成本通常很低，因此可以优先保证 GPT-Live 的实际体验和探索空间。

对于长时间没有交互的场景，可以考虑使用 Standby，或者直接关闭会话，避免不必要的持续费用。

---

## 6. 额度与计费规则

本计划使用 ChatGPT Pro 提供的每月 $100 API Credit。

- GPT-Live 和 Decisions API 均属于官方 API Credit 覆盖范围。
- 两项服务的费用均从关联的 API Organization 额度中抵扣。
- 两项服务分别按照各自的计费规则结算。
- 后端模型和工具的额外费用也会计入 API Organization。
- API Credit 按订阅账单周期发放。
- 当期未使用的赠送额度不会累计到下一个周期。
