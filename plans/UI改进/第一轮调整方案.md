# Agentelier UI 第一轮调整方案

根据本轮截图讨论，对主窗口、导航栏、Session 管理、设置页面以及 Skill、MCP、Memory 管理窗口进行统一调整。

本轮以已经确定的设计为准，不重新规划现有功能。

---

## 一、主窗口整体布局

### 1. 顶部标题栏

- 移除原有顶部状态信息，包括额度、Token 用量、服务端用量等信息。
- 将原本位于最左侧的竖向图标导航栏迁移到顶部标题栏。
- 保留登录和设置图标。
- Skill、MCP、Memory 使用新生成的 SVG 图标。

### 2. 移除不再需要的区域

- 移除右侧后台任务区域。
- 移除后台任务区域与聊天区域之间的竖向分隔 Bar。
- 移除主聊天区域顶部原有的独立配置区域（第一张截图标记为 4 的整个区域）。

### 3. 固定主窗口布局

左侧 Session 管理区与右侧主聊天区域采用固定的 3:7 比例：

- 左侧 Session 管理区：30%。
- 右侧主聊天区域：70%。
- 两者之间保留分隔 Bar，但不允许拖动调整宽度。
- 整个主窗口禁止 Resize，不允许通过拖动边缘或角落改变窗口尺寸。

### 4. 窗口圆角

目前主窗口和设置窗口都存在圆角显示不完整的问题。

需要检查窗口边缘和圆角裁切，确保四个角完整显示，不出现背景溢出或边角缺失。

---

## 二、顶部导航图标

保留原有登录和设置图标，另外三个图标替换为已经确定的设计：

| 功能 | 图标 | 文件 |
|---|---|---|
| Skill | Workflow | `skill.svg` |

- 2px 描边。
- `currentColor`，支持主题颜色。
- 透明背景。

## 三、左侧 Session 管理区域

### 1. 区域划分

将左侧内容明确分为两个独立区域：

- 项目
- 单独聊天

两个区域分别展示各自的内容。

### 2. 新建操作

删除原有三个按钮：

- 新建项目
- 新建单独聊天
- 刷新本地会话

改用类似 ChatGPT 网页版的交互：

- 鼠标悬停在「项目」标题上，右侧显示 `+`。
- 点击 `+` 创建项目。
- 鼠标悬停在「单独聊天」标题上，右侧显示 `+`。
- 点击 `+` 创建独立聊天。
- 未悬停时隐藏 `+`。

### 3. Session 操作菜单

鼠标悬停在某个 Session 上时，右侧显示 `...` 按钮。

点击后弹出菜单，只保留：

- 重命名
- 归档
- 删除

不需要置顶、分享、锁定、移动到项目、从项目中移除等功能。

### 4. Session 运行状态

每个 Session 需要显示自己的运行状态：

| 状态 | 显示方式 | 行为 |
|---|---|---|
| 空闲 | 不显示图标 | 没有正在执行的任务 |
| 忙碌 | 圆形转圈动画 | 模型回复、工具调用或其他任务仍在执行 |
| 出错 | 红色感叹号 | 模型回复失败、工具调用失败、额度不足等异常 |

具体规则：

- 只要还有任务需要执行，就显示转圈。
- 模型回复和工具调用期间都属于忙碌状态。
- 所有任务正常完成后，隐藏状态图标。
- 出现异常时显示红色感叹号，不再显示忙碌转圈。

状态图标放在 Session 条目右侧，与 `...` 操作按钮协调排列。

## 四、设置页面调整

### 1. 窗口标题

「设置」标题增加左侧内边距，不要紧贴窗口边缘。

### 2. 数据目录

- 数据目录输入框缩短。
- 「更改数据目录」按钮移动到输入框右侧。
- 两者放在同一行。

### 3. 默认模型

不再重复显示模型名称和内部模型 ID。

只显示用户能够识别的模型名称，例如：

`GPT-6.2-Sol`

不再显示后面的 `gpt-6.2-sol`。

### 4. 默认值保存状态

删除保存按钮旁边的「已保存 gpt-6.2-sol · high」状态文字。

### 5. 布局设置

整个布局设置区域删除，包括：

- 会话栏宽度 Slider。
- 右侧区域宽度 Slider。
- 对应的布局配置项。

因为主窗口已经确定采用固定的 3:7 布局，不再需要用户调整。

### 6. 用户头像

设置页面只保留头像本身。

交互调整为：

**选择图片：**

1. 用户点击头像。
2. 打开系统文件选择窗口。
3. 用户选择图片后，打开独立的头像编辑窗口。

**头像编辑窗口：**

- 显示选中的原始图片。
- 提供圆形裁剪 Mask。
- 可以拖动 Mask，选择需要显示的图片区域。
- 可以缩放 Mask，调整裁剪范围。
- 实时预览最终头像效果。
- 窗口内提供「保存」和「取消」按钮。

保存后将裁剪结果应用为用户头像；取消则放弃本次修改。

**设置页面本身：**

- 删除头像缩放 Slider。
- 删除「更换图片」按钮。
- 删除「保存头像」按钮。
- 删除独立的「移除头像」按钮。
- 在头像右上角增加一个小型红色 `×`，点击后移除当前头像。

## 十、本轮调整的整体原则

1. 减少不必要的独立功能区域，让主聊天区域获得更多空间。
2. 将导航入口整合到顶部标题栏。
3. 将 Session 的创建、管理和运行状态整合到左侧区域。
4. 主窗口采用固定尺寸和固定 3:7 布局。
5. Skill、MCP、Memory 管理窗口采用统一的窗口行为。
6. 设置页面删除不再需要的布局配置和重复信息。
7. 头像编辑采用独立窗口，避免将编辑功能堆积在设置页面。
8. 主聊天和 Memory 聊天统一发送按钮的视觉和交互方式。

本轮只调整上述已经讨论并确定的内容，不额外扩展功能，也不改变未涉及的现有行为。
