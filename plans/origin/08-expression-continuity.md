# 在真实压缩后保留少量最近表达线索

本增量只解决一种情况：当前 Session 的真实 compaction 已经让最近相关的公开回复不再位于活动工作窗口，而当前交流确实需要连续性辅助。它不对每轮回答做风格检查。

## 只在历史缺失时补充

正常聊天已有完整 Session 历史，不需要重复注入近期表达。只有确认 compaction 覆盖了最近相关 final，且当前任务需要自然对话连续性时，才从同一 Session 取得最近最多五条已完成 Root 公开回复的简短开头摘录。

每条最多 48 个 Unicode 字符，总计最多 320 字符。不得跨 Session 或 Project；不得读取工具回执、其他 Agent 的内部发言、凭据、敏感内容或已撤下派生记忆。当前窗口仍有原文、无法确认来源或不能安全判断内容时省略。

摘录作为有界历史材料加入请求准备，说明它只用于避免无意识重复和维持连贯，不是词语禁令、格式配额或新用户消息。使用同一逻辑任务/压缩窗口已确定材料；认证重发复用冻结字节。没有候选时不发送空提示块。

## 完成条件

- 正常多轮闲聊和技术讨论中，当前窗口已有原文时不额外注入摘录。
- 在真实发生的 compaction 后，只有最近相关 final 确实不在活动窗口时才注入；核对同一 Session 来源、条数、字符上限、内容安全和请求位置。
- 专业术语、公式和接口名重复不会触发过滤或改写。
- 原始 final 保持不变；没有额外重写请求、相似度拦截器或自动丢弃回答。
- 如果验收期间没有自然发生满足条件的 compaction，记录为未覆盖，不制造无意义大请求。

## 工程边界

- 目标环境为 Windows x64、`x86_64-pc-windows-msvc`、DX12 与 PowerShell 7；不为未要求的平台增加兼容层。
- 遵守现有 Workspace / Crate 职责和依赖方向。业务实现放在 `crates/`，不在 `app/` 增加业务逻辑；不修改 Bevy、Widgetry、BRP 或 Codex 上游源码。
- 复用 Account、LLM Model、Runtime、Conversation、Session Store、Memory、Project Context、Skills、ToolCatalog 和现有异步任务机制；不建立平行 Agent Registry、任务数据库、记忆数据库或 Skill 管理器。
- 不恢复用户可见的提示词管理页面、Project Skill 或人格工作台。不得通过人格、记忆或 Skill 扩大工具权限。
- 不接入 B 站账号，不执行浏览、评论、私信、上传、直播、定时发布或其他平台运营。
- 未经用户明确授权，不退出登录、不重新登录、不切换账号、不重置凭据，也不通过更换数据目录破坏登录状态。
- 项目禁止新增或修改测试代码、Benchmark 和 Example。按变更范围使用 Cargo 编译、格式、Clippy、真实应用运行、日志/请求/存储状态核对；涉及 GUI 可观察行为时必须使用实际应用和 `bevy_brp_mcp` 验证。
- 不声称未执行的验证已经通过。发现问题在对应功能增量内修复并复验受影响范围，不另设纯验收阶段。
