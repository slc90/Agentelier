# 下线 SIWC 并收束到 Codex OAuth

Agentelier 对话及相关模型消费端都能使用 Codex OAuth 后，删除 SIWC 登录与专属请求路径。用户用账号区选择由 Codex 管理的 `auth.json`。已有会话、附件、工具记录和长期记忆仍由原有本地存储管理。

## 下线的前置条件

- [模型目录和普通对话](02-codex-model-routing.md)已在真实应用中覆盖目录、连接验证和多轮文本请求。
- [凭据生命周期](03-external-credential-lifecycle.md)已覆盖同一主体的外部更新、过期后的状态与恢复，以及换账号或工作区时旧执行的停止。账号与工作区场景使用获授权的凭据或适合的验证材料，按实际观测记录结果。
- [原生异步工具](04-codex-native-async.md)已覆盖同步调用、跨 Turn 结果交付及取消收尾。核对仍依赖模型的后台消费者，包括长期记忆提取和整合，确认它们能通过同一个 Codex 请求入口运行。
- 用有代表性的 SIWC 旧存档验证恢复。能安全接续的会话在 Codex 下完成一轮。模型、工具声明、历史协议或身份无法兼容时，历史和附件仍可打开，界面给出原因并允许显式新建会话。旧工具结果保持原调用归属。

## 下线后的账号与请求

账号区保留 Codex 文件的选择、替换、状态和断开。断开后进入未连接状态并提示选择有效文件。本地会话和已发布记忆仍可阅读。配置继续保存外部文件路径，选择、断开和重启沿用原有持久化边界。

移除 SIWC 浏览器授权、动态客户端登记、订阅同意、Token 续期、远端退出撤销、账号界面入口及专用 `api.openai.com/v1` 路由。清理这些行为独占的状态、命令和依赖。Account、执行身份失效、请求冻结、工具收尾及存储确认继续由现有执行链维护。

旧数据目录中的 SIWC `auth.json` 留在原位。启动、数据目录检查和运行期间都跳过它，避免旧文件权限影响 Codex 启动。Codex 外部文件继续只读，由官方客户端管理更新。会话存档沿用原记录和冻结设置，旧凭据、旧请求和旧工具调用均不会被转换为新授权下的执行。

## 验收

BRP 验证账号区只有 Codex 凭据入口，路径能在重启后恢复。断开或文件失效时，目录读取、模型调用和后台记忆请求暂停，旧会话仍可浏览。重新选择有效文件后，目录恢复，新会话可以聊天并完成一次代表性的原生异步工具调用。

从仍有 SIWC 文件的现有数据目录启动，确认应用可进入主界面并读取旧会话，运行中无 SIWC 模型、刷新或撤销请求。核对两份凭据文件均保持原内容。通过必要的 Cargo 静态检查、构建和受影响 GUI 的实际 BRP 验证。

[图片生成](05-image-generation-tool.md)在下线后实施，它使用已接通的 Codex 授权和工具链。
