# 10：保留列表层级和代码格式

本增量在已有原生 Markdown 展示中加入有序、无序及嵌套列表和围栏代码块。技术文档中的步骤和代码需要保留结构，不能被当成连续段落压平。

## 使用已有解析与更新路径

沿用 ui/markdown 的 pulldown-cmark 事件适配、原文缓存和 BSN 构造。增加必要的块表示与样式，不为列表或代码建立第二个解析器。

列表保留层级、有序起始编号和条目中的段落。代码块保留缩进、换行、空行和语言标签；长行在代码区内横向浏览，不撑破整体消息区域。先显示可靠的等宽文本，语法高亮不作为完成条件。

围栏未闭合的生成中内容仍能阅读。收到完成输出后按最终全文校准，不能在正文中自动补入闭合符后写回模型历史。Mermaid 围栏显示为代码，不称为图表渲染。

## 交互保持独立

列表与代码更新不能抢输入焦点，也不能覆盖用户向上阅读的滚动位置。主题或宽度变化只改变展示，不重置模型正文。后续复制入口可以使用此处保留的原文区间，但本增量不加入新的内容存储。

## 完成与验证

通过真实应用展示多层列表、条目中包含段落、长行代码、空行与未闭合围栏，观察流式中间态和最终态。BRP 验证代码区滚动与消息区滚动互不混乱。检查窄窗口、中文混排和主题变化。

执行静态检查，更新已实现 Markdown 语法说明。实际应用验证遵守 BSN 与 Widgetry 公共契约，不创建测试代码、Benchmark、Example 或专用演示程序。
