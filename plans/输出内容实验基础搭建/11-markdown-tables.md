# 11：显示 GFM 表格和只读任务列表

本增量补齐文档比较常用的表格和任务列表。表格保持真实行列关系，不用把整个表格当作一个带竖线的字符串来模拟。

## 行列与宽度

启用解析器相应扩展，在 ui/markdown 中保留表头、单元格与对齐信息。使用原生布局组合表格，优先考察 Widgetry Table 的公开能力是否适合只读、动态正文；不合适时在同一 Markdown crate 内用 BSN 组合布局，不修改上游内部实现。

表格在消息宽度内优先可读排版，空间不足时由表格区域横向滚动。不能把所有列压缩成单字竖排，也不能让表格把整个聊天页推到窗口外。表格单元格中的基本行内格式复用已有能力。

任务列表呈现勾选与未勾选状态，但本阶段只读，不把点击行为变成修改模型回答。

## 生成中与完成后

表格头或分隔行尚未完整时，按当前解析结果显示文本或部分结构。后续内容补全后重新解析活动消息，最终以完整原文为准。布局变化不能造成重复行、丢失单元格或重置整个页面滚动。

## 完成与验证

在真实聊天中生成包含中文表头、多列、长单元格、对齐符号和任务列表的文档。BRP 检查宽窄窗口下的横向浏览、页面纵向滚动和流式补全；在有效原文中核对表格内容未被显示适配修改。

执行静态检查，更新支持范围与已知限制。只依赖官方库与 Widgetry 公共接口，UI 使用 BSN，不新增测试代码、Benchmark 或 Example。
