# 12：查看和复制未经改写的回答

本增量保证用户既能看排版，也能取得原始 Markdown。这使长回答和文档能够直接复制使用，不增加自动历史持久化。

## 展示与原文切换

每条助手消息提供查看原文与复制正文入口。原文区域使用 WidgetryReadOnlyTextField 或同等公开只读编辑能力，支持选择、导航与复制，不把它禁用成无法选择的装饰文字。

复制正文得到原始 Markdown，排除角色标题、状态标签和按钮文字。代码块复制只取对应代码内容，保留空行、缩进和换行，不添加围栏或语言标签。失败或取消的部分回答也能复制，但 UI 状态继续说明其未完成。

## 流式复制

生成期间复制获取当前原文快照，不停止模型，也不锁住后续更新。查看原文时新内容继续增长；退出原文查看恢复渲染视图，不重新发送请求。

本阶段不要求跨多个渲染块统一拖选。原文区域提供完整可选择文本即可满足材料取得，避免为此重写整个 Bevy 文本选择体系。

## 完成与验证

通过真实界面复制一段含中文、代码缩进和表格的回答，在应用可读取的剪贴板或本机目标中核对内容。BRP 验证按钮与原文选择；工具无法覆盖的跨应用粘贴如实记录并做本机检查。

检查进行中的复制不重复、最终复制不含状态文本、失败片段保持状态。执行静态检查与文档同步，不自动写入聊天日志，不引入测试、Benchmark 或 Example。
