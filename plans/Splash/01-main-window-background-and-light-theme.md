# 主窗口共享背景与浅色主题

## 目标

让 Agentelier
主窗口使用已经确定的浅薄荷绿字符少女背景，并将当前偏暗的主窗口表面调整为与背景协调的浅色体系。Splash
后续会使用同一张图片，因此背景资源、窗口尺寸和缩放方式在这一增量中统一。

## 共享背景资源

最终背景素材来自已确认的 Splash 原型资源
`assets/main_window_background_reference.png`。它是一张浅薄荷绿底色、包含低对比度字符少女形象的完整背景图，比例接近
16:9。

将同一份图片资源加入 Assets crate，例如：

```text
crates/ui/assets/src/assets/backgrounds/main-window-background.png
```

`AppAssetPlugin` 负责嵌入并加载该图片，向 application 和主窗口 UI
提供同一个 `Handle<Image>`。不要在 Splash
和主窗口分别生成或编辑两张近似图片。

主窗口在 `startup.rs` 的 `@widgetry_window` 中使用
`WidgetryWindowBackground::Image`，选择 `Cover`
模式并保持完整背景不透明。主窗口尺寸采用现有 UI 设计确定的 1920 ×
1080；图片与窗口均为 16:9，因此不会产生明显裁切差异。Splash
后续使用主窗口的实际物理尺寸，保持相同画面比例。

当前实现的 `initial_window()` 使用 1100 × 760，而主工作区在
`DataDirectoryReady` 后调整为 1920 × 1080。为避免 Splash
结束时窗口尺寸突然变化，初始主窗口也调整为 1920 ×
1080。数据目录选择、检查和失败页面继续使用同一个主窗口，只是内容不同；`enter_main`
保留标题和主工作区约束更新，不再造成尺寸跳变。

## 主窗口表面与文字可读性

背景图负责提供空间氛围和助手形象，不直接承载聊天正文。实际文字、代码和交互控件仍然使用独立的表面颜色。空白工作区可以透出背景，承载文字的控件不能完全透明。

主窗口采用以下颜色关系。颜色值取自最终 Splash 原型中的界面预览，作为
`AGENTELIER_THEME` 和主工作区背景常量的统一基准：

| 用途         | 颜色      |
|:-------------|:----------|
| 工具栏表面   | `#F4FBF6` |
| 左侧导航表面 | `#EDF6EE` |
| 后台任务表面 | `#F2F8F1` |
| 当前选中项   | `#D8EBDF` |
| 聊天消息表面 | `#F6FBF7` |
| 输入区域表面 | `#F7FBF7` |
| 代码块表面   | `#E4F0E8` |
| 代码块边框   | `#D0E4D6` |
| 主文字       | `#213D32` |
| 标题文字     | `#24483A` |
| 次级文字     | `#456656` |
| 代码文字     | `#145342` |
| 普通边框     | `#B8D2C3` |
| 主按钮       | `#235E47` |
| 主按钮文字   | `#EEF8EF` |

`AGENTELIER_THEME` 继续通过 Widgetry Theme
的语义角色提供颜色，不在每个控件中重新硬编码整套状态颜色。同步检查
`chat_ui` 中独立定义的 `SIDE_BACKGROUND`、`PANEL_BACKGROUND`
等常量，避免主题已经变浅，但局部面板仍保留旧的深绿底色。

需要覆盖的表面包括：

- 顶部工具栏和左侧导航。
- Session 导航中的选中项、悬停项和列表内容。
- 聊天消息正文容器。
- Markdown 代码块。
- 输入框与模型选择区域。
- 后台任务区域及其任务条目。
- 首次启动的数据目录选择、检查和失败页面。

消息内容可以使用独立的浅色消息表面，聊天区域未被内容占据的部分继续显示背景图。代码块和输入区域使用自己的表面，不让背景字符穿透正文。

助手字符形象属于窗口背景，不增加新的 F 区控件，也不改变 D
区消息头像的资源所有权。D 区助手头像仍使用现有头像资源。

## 与后续 Splash 的关系

主窗口与 Splash
必须共享同一张背景图片、同一窗口比例和同一缩放规则。Splash
的最终帧直接显示这张图片；主窗口在其上方显示 UI 控件。这样 Widgetry 移除
Splash 窗口后，背景不会发生人物位置、大小或色彩变化。

## 完成条件

- 背景图片作为 Assets crate 的嵌入资源加载，主窗口使用该资源。
- 主窗口初始尺寸与既定 1920 × 1080
  设计一致，数据目录就绪后不再产生尺寸跳变。
- `AGENTELIER_THEME` 和主工作区硬编码背景常量统一为浅薄荷绿体系。
- 聊天正文、代码块、输入区域和任务内容具有足够不透明的表面，文字不直接压在字符水印上。
- 主窗口空白区域仍能看到浅薄荷绿字符少女背景。
- 辅助窗口和已有控件状态没有因主题调整而出现不可读的文字或按钮。
- 背景图片可作为 Splash 与主窗口的共享资源使用。

验证通过实际 Windows 窗口观察与 BRP 检查完成；遵循项目现有约束，不新增
Unit Test、Integration Test、Regression Test、Benchmark 或 Example
代码。
