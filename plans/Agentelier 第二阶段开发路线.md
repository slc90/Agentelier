# Agentelier 第二阶段开发路线

## 开发顺序

| 顺序 | 功能              | 完成后能做什么                                                                                                     |
| ---- | ----------------- | ------------------------------------------------------------------------------------------------------------------ |
| 1    | **人格设计**      | 定义 Agentelier 的固定人格、性格特征、交流方式、思考习惯和行为原则。                                               |
| 2    | **UI 与交互设计** | 改进聊天页面，设计任务管理、助手设置、记忆管理等页面，让用户能够自然地与助手交流、管理和协作。                     |
| 3    | **提示词管理**    | 建立分类管理机制，分别管理人格、聊天、任务规划、执行、结果检查等不同场景下的提示词。                               |
| 4    | **持续任务推进**  | 让 Agentelier 能够自主规划任务、持续执行、检查结果、调整计划并从失败中恢复，直到任务完成或遇到需要用户介入的情况。 |
| 5    | **长期记忆**      | 改进长期记忆机制，区分固定人格、用户偏好、项目知识、历史经历和任务状态，实现跨会话的信息积累与复用。               |
